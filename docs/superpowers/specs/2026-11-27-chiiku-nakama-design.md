# 設計書：ちいく「なかまわけ」

## 1. 目的
- 5歳の子が、絵を「なかま」ごとに かごへ 分ける。ものを 分けて 考える力。
- 分け方は「もの」だけでなく、色・とぶ／とばない・たべられる／たべられない・大きさ も ある。同じ りんごでも、分け方で 入る かごが かわる ことに 気づく。

## 2. 決めたこと（やまとさんと決めた、2026-11-27）
| 項目 | 内容 |
|---|---|
| 分け方 | 5つ：もの・いろ・そらを とぶ／とばない・たべられる／たべられない・おおきさ |
| おおきさ | ほんものの 大きさ。はっきり 差が あるものだけ（ぞう・くじら と あり・てんとうむし など）。画面に 描いた 大きさでは 分けない |
| 絵 | Figma の AI で 作る（絵文字は 使わない。端末で 色が かわるため） |
| 出し方 | 分け方を まぜて 出す |
| 読み上げ | レベル1・2：分け方を 読み上げる。レベル3：読み上げず、かごの 見本を 見て 考えさせる |
| あそび方 | 絵を 指で 引っぱって かごへ（絵を タッチ → かごを タッチ でも よい） |
| 正しい かご | ポンと 入って「りんごは くだもの！」 |
| ちがう かご | 絵が もとに もどり「もういっかい やってみよう」（叱らない） |
| ひんと | しばらく 止まると、のこっている 絵と その かごが 光る |
| ごほうび | 全部 入れたら かごが ゆれる。5問で ごほうび画面 |

## 3. レベル〔作る人の判断を ふくむ〕
| レベル | 分ける絵 | かご | 読み上げ |
|---|---|---|---|
| 1 | 4まい | 2つ（「もの」は まったく ちがう なかま どうし） | 分け方を 言う。かごに 名前 |
| 2 | 6まい | 2つ（「もの」は にている なかま：くだもの・やさい／どうぶつ・うみの いきもの／どうぶつ・むし） | 分け方を 言う。かごに 名前 |
| 3 | 6まい | 「もの」「いろ」は 3つ、ほかは 2つ | 「かごの なかを みて、なかまを かんがえてね」だけ。かごに 名前なし。3回 まちがえたら 分け方を 言う |
- どの レベルも、かごには はじめから 見本の 絵が 1まい 入っている。
- レベル3 は、ほかの 分け方でも 分けられて しまう 組み合わせ（例：「たべられる」の 問題なのに、くだもの と どうぶつ だけ）は 出さない。
- 1回分（5問）で、5つの 分け方が 1回ずつ 出る（じゅんばんは ばらばら）。

## 4. 絵と なかま（45まい）
- もの：くだもの7・やさい7・どうぶつ9・うみの いきもの7・のりもの8・むし7。
- いろ：あか（りんご・いちご・とまと・たこ・かに・しょうぼうしゃ・てんとうむし）／あお（ことり・くじら・いるか・くるま）／きいろ（ばなな・れもん・とうもろこし・ひとで・ばす・はち）。あか と みどり の 組み合わせは 使わない（色の 見分けが 苦手な 子への 配慮）。色が まざった 絵は 色の 問題に 出さない。
- とぶ：ことり・ひこうき・へりこぷたー・ききゅう・てんとうむし・ちょうちょ・はち・とんぼ・せみ。かぶとむしは 出さない（とぶか まよう）。
- たべられる：くだもの・やさい。たべられない：どうぶつ・のりもの・むし。うみの いきものは 出さない（たべられる ものも あって まよう）。
- おおきい：ぞう・きりん・かば・くじら。ちいさい：ねずみ・あり・てんとうむし・ちょうちょ・はち・とんぼ・かぶとむし・せみ。
- 絵は 1まいの 画像に 9こずつ ならべて 作り、切り分けた（`archive/proto-src/nakama/cut.sh`）。256×256 の jpg。かご（透明の png）と 背景も Figma。

## 5. 記録
- `area: 'nakama'`、`itemId`：分け方（`mono` `iro` `tobu` `taberu` `ookisa`）、1問1件。まちがいが 0回なら true。親画面の 表示名は「なかまわけ」。

## 6. 画面
- 上に 分ける絵（白い カード）、下に かご。スクロールなし（8つの 画面の 大きさ）。カード・かごは 56px 以上。
- 背景は うすい 水彩画（Figma）。

## 7. 読み上げ（新しく 作る）
- 分け方：「なかまに わけよう！」「いろで わけよう！」「そらを とぶかな？ とばないかな？」「たべられるかな？ たべられないかな？」「おおきいかな？ ちいさいかな？」「かごの なかを みて、なかまを かんがえてね」
- 入れたとき：「（絵の名前）は （かごの名前）！」、全部：「ぜんぶ わけられたね！」、かごを さわる：かごの 名前。
- ある 音声：「どれに する？」「もういっかい やってみよう」「すごい！ よく できたね」。
