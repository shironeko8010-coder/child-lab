# スマホで画面が見切れる不具合の修正 報告

## 不具合
やまとさんの実機報告：「アンドロイドスマホで試したら見切れしている」。
タブレット向けの固定サイズ（絵 120〜300px、文字 44〜104px、ボタン 72〜120px）のままで、スマホの高さ（横向き 300〜412px）・幅（縦向き 360〜412px）に収まっていなかった。

## 修正前の計測（ブラウザ内蔵ツールで画面サイズを切り替えて、DOM の位置を計測）
| サイズ | 画面 | 症状 |
|---|---|---|
| 800x360 横 | プロフィール | 「はじめる」が下にはみ出し（ページ高さ 510px） |
| 800x360 横 | ホーム | キャラと文字が折り返して縦に並び、「あそぶ」が y=558〜678 で画面外 |
| 800x360 横 | えらぶ | カードが y=224〜424 で下が切れる |

## 直した箇所
### shared/ui.css
- `:root` に `--vh`（`1vh`、対応端末では `@supports` で `1dvh`）を追加。アドレスバーで変わる実際の高さを使うため。
- `:root` に安全領域 `--safe-t/r/b/l`（`env(safe-area-inset-*)`）を追加。
- スマホ横向き（`orientation: landscape` かつ `max-height: 520px`）だけ `--tap-min` を 56px に下げる。タブレット（高さ 600px 以上）は 64px のまま。
- `.screen` を `min-height: 100dvh`（`100vh` にフォールバック）にし、余白に安全領域を加えた。
- おとなゲート（gate.js が出すスタイル）を `html #chiid-gate ...` で上書き（gate.js 本体は触っていない）。
  - ゲートの外側の余白に安全領域。箱は `max-height/max-width: 100%`（以前は 96vh＝アドレスバー分ずれる）。
  - スマホ横向き：キー 60px、高さ 340px 以下では 56px。
  - スマホ縦向き：キー 64px、文字を少し縮めて縦に収める。

### app-chiiku/app.css
- `.app` の余白に安全領域を加えた（タブレットでは安全領域が 0 なので見た目は変わらない）。
- 新しいメディアクエリを3つ追加（既存のタブレット向けルールはそのまま）：
  1. **スマホ横向き** `(orientation: landscape) and (max-height: 520px)`：上の帯のボタン 56px、各画面の絵・文字・ボタンを `calc(var(--vh) * N)` と `clamp()` で高さに合わせて縮める。ホームは横並びを維持（折り返さない）、プロフィールは入力欄と「はじめる」を横並び、えらぶはヘッダー1行＋カード1行、なぞるはキャンバス `min-height` を外して高さに合わせる。
  2. **さらに低い横向き** `(orientation: landscape) and (max-height: 340px)`（アドレスバーが出ているスマホ横向き）：なぞる画面のキャラを隠し、ボタンと文字を優先。
  3. **スマホ縦向き** `(orientation: portrait) and (max-width: 520px)`：タップ領域は 64px 以上のまま。えらぶのカードを2列グリッド（3枚のときは3枚目を中央）、ヘッダーのキャラ・文字を幅と高さに合わせて縮小、なぞるのキャラとふきだしを横並びにして「できた！」が折り返さないようにした、ごほうびの星・キャラ・文字を縮小、親画面の左右余白を減らした。
- game.js は変更していない。

### index.html（`<style>` のみ）
- スマホ横向き：カード・絵・見出しを高さに合わせて縮める。
- スマホ縦向き：カードを幅 80vw までにし、高さに合わせて絵を縮める。
- viewport meta は、すでに `viewport-fit=cover` が入っていたので変更なし（app-chiiku/index.html も同じ）。

## 未確認事項
- **実機（Android スマホ・タブレット）では確認していない。** ブラウザのサイズ切り替え（エミュレーション）での確認のみ。アドレスバーの出入り・ナビゲーションバー・切り欠き（安全領域）・画面回転の実際の動きは、実機での確認をお願いしたい。
  - 試す例：スマホ横向きで「あそぶ」→ カードを選ぶ → なぞる → ごほうび。期待：どの画面もスクロールせずに全部見え、「できた！」「つぎへ」が押せる。縦向きでも同じ。
  - アドレスバーが出ているとき・隠れたときの両方で、下のボタンが切れないこと。
- プロフィール作成で文字入力キーボードが出たときは、画面の高さが大きく減る（横向きだと 150px 程度）。このときは縦スクロールで入力欄と「はじめる」に届く作り（全部を1画面に収めるのは不可能）。実機での使い勝手は未確認。
- 幅 520px 超・高さ 520px 超の中間サイズ（小型タブレットや折りたたみ端末）は、従来のタブレット向けの見た目のまま。今回の6サイズ以外は計測していない。
