# 設計書：読み上げを「ずんだもん」の音声ファイルにする

## 1. 目的
- アプリ全体の読み上げを、自然な日本語にする。
- 声は VOICEVOX の「ずんだもん（ノーマル）」。話し方の語尾は変えない（今の文のまま読む）。
- 通信なしの決まりは守る。音声は先に作ってアプリに入れておく。

## 2. しくみ
```
（作るとき：PCの中だけ）
  アプリの文を集める ─▶ lines.tsv ─▶ VOICEVOX で音声を作る ─▶ ffmpeg で小さくする
                                                       └▶ voice/z/<id>.ogg と shared/voice-clips.js

（使うとき：タブレット）
  speak(文) ─▶ voice-clips.js に文がある？ ─ある─▶ 音声ファイルを鳴らす
                                    └ない─▶ 今までどおり端末の声で読む
```

| 項目 | 決めたこと |
|---|---|
| 声 | ずんだもん ノーマル（VOICEVOX の speaker 3） |
| 音声の形式 | OGG（Opus 24kbps・モノラル）。2,825文で約24MB |
| 置き場所 | `voice/z/<id>.ogg`。`<id>` は文から作る短い番号（md5 の先頭10文字） |
| 文と音声の対応表 | `shared/voice-clips.js`（`C.voiceClips = { "文": "id", … }`）。作るスクリプトが書き出す |
| 文の見分け方 | 文から ふりがなの記号・空白を取り除いたもの（`{話|はな}して みてね` → `話してみてね`）。表記がちがっても読みが同じなら同じ音声を使う |
| 鳴らし方 | `<audio>`（HTMLAudio）。鳴らしている間は BGM を小さくする（今と同じ） |
| 鳴らせないとき | 対応表にない文・ファイルが読めない・再生に失敗した → 端末の声で読む（今のしくみを残す） |
| オフライン | `sw.js` で音声ファイルも全部保存する。CACHE_NAME を上げる |
| 速さ | speedScale 1.0（ふつうの速さ。試聴して決めた） |
| 音の大きさ | ffmpeg で全部の音声の大きさをそろえる |

## 3. 文のつなぎ方（部品方式）
1つずつ作ると多すぎる文だけ、部品に分ける。区切りは、画面には出ない記号 `｜` で示す。
- `speak('23たす｜45は？')` → 対応表に「23たす」「45は？」の両方があれば、続けて鳴らす。どちらかがなければ、`｜` を取った文を端末の声で読む。
- 「は」は、数字とくっつけて「45は？」にする（「は？」だけだと「ハ」と読むため）。

| 文 | 部品 | 数 |
|---|---|---|
| 計算の問題 | 「N たす」「N ひく」＋「N は？」（N は 0〜199） | 約400 |
| 計算・九九の答え | 「こたえは N だよ。」（N は 0〜199）＋「つぎは できるよ！」 | 約200 |
| ほしの数 | 「ほしが Nこ」 | 約10 |

九九の問題（162通り）は、部品にしないで1文ずつ作る。

## 4. 作れない文
- **ニックネームが入る文**（「こんにちは、たろう！」など）は、端末の声のまま。
  - 名前の部分だけ端末の声にすると、声がまざって不自然になるため。
- 対応表にない文は、端末の声で読む。テストで「集めた文がすべて対応表にあるか」を確かめる。

## 5. 文の集め方
`tools/voice-lines.html` をブラウザで開くと、アプリの読み上げ文をすべて書き出す。
1. 決まった文：各教科の `speak('…')` に直接書いてある文。
2. 作られる文：各教科のデータから作る文。九九の式・かん字の問題・都道府県・国・どうとくの場面など。
   - 教科ごとに `voiceLines()`（その教科で読む文をすべて返す関数）を足す。
3. 部品：3章の部品。

**取りこぼしを見つけるしかけ**：開発用の設定のときだけ、対応表になかった文を localStorage に記録する。QA で一通り遊んで、もれを拾う。

## 6. 読みのまちがい対策
- VOICEVOX には、漢字のまま渡す（イントネーションが自然になるため）。
- 作るとき、VOICEVOX が出した読み（カナ）と、文のふりがな（`{漢字|よみ}`）を自動で比べる。
- ちがう所は一覧にする。VOICEVOX のユーザー辞書（単語の読みを登録する機能）か、その文だけ ひらがなで渡す方法で直す。
- 一覧は、やまとさんにも見てもらう。

## 7. 作るスクリプト（Bash から perl で動かす。PowerShell は使わない）
- `tools/voice/make.pl`（perl）：`lines.tsv` を読み、まだない音声だけを作る。対応表を書き出す。
  - VOICEVOX（`http://127.0.0.1:50021`）に curl で頼む。文はファイル経由で渡す（コマンドに日本語を直接書くと文字化けするため）。
  - 作るときだけ、やまとさんのPCで VOICEVOX を起動しておく。
- 文を直したら、もう一度 `make.pl` を流す。変わった文だけ作り直す。使わなくなった音声は消さずに `voice/_old/` へ移す。

## 8. クレジット表記
- ずんだもんの利用規約により、クレジット表記が必要。
- 親画面に「このアプリについて」を置き、「音声：VOICEVOX:ずんだもん」と書く。
- VOICEVOX のソフトそのものは、アプリに入れない。

## 9. テスト
- voice.js：対応表にある文は音声ファイルを鳴らす。ない文・再生失敗は端末の声になる。`｜` の部品方式（全部ある／1つ欠ける）。
- 集めた文がすべて対応表にあり、その音声ファイルが存在する。
- 計算の `speakText` が部品の形（`｜` 入り）を返す。
- 親画面にクレジットがある。
- 実機（Androidタブレット）で、音が出るか・オフラインで鳴るかを、やまとさんに確かめてもらう。

## 10. 未確認・制約
- iPhone・iPad の Safari は、古い版だと OGG を鳴らせないことがある。今は Android タブレットが対象なので OGG にする。必要になったら MP3 で作り直せる（約30MB）。
- 初めて開いたときに約24MBの保存が走るので、少し時間がかかる。
- 新しい教科（「おかいもの」「長さ・かさ」）は、この方式ができてから作り、最初から音声ファイルを用意する。

## 11. 使い方（文を足したり直したりしたとき）
作業は Claude が Bash で行う。やまとさんは、VOICEVOX を起動しておくだけでよい。
1. 新しい教科・文を足したら、`tools/voice-lines.js` に、その教科の文の作り方を足す。
2. `perl tools/serve.pl . 8765` でサーバーを動かし、`http://localhost:8765/tools/voice-lines.html` を開く。→ `tools/voice/lines.tsv` と `ruby.tsv` ができる。
3. 読みだけ先に調べる：`perl tools/voice/make.pl --preview` のあと `MADE=tools/voice/preview.tsv perl tools/voice/check.pl`。→ `tools/voice/check.tsv` に、あやしい文が出る。
4. 読みがおかしい言葉は `tools/voice/yomi-fix.tsv`（ことば→読み）に、1文だけの直しは `tools/voice/overrides.tsv` に書く。
5. 音声を作る：`perl tools/voice/make.pl`。新しい文・直した文だけ作る（1文 約2.5秒）。`shared/voice-clips.js` が書きかわる。
6. `sw.js` の CACHE_NAME を上げる。`tests/index.html` で「すべて音声ファイルがある」テストが通ることを確かめる。

## 12. 困ったとき
| こまったこと | 対処 |
|---|---|
| make.pl が「VOICEVOX が起動していません」と止まる | VOICEVOX を起動してから、もう一度流す（作り終えた分は残っている） |
| 日本語がでたらめに読まれる | コマンドに日本語を直接書かない。make.pl はファイル・HTTP で渡しているので、そのまま使う |
| 1つの言葉の読みがちがう | `yomi-fix.tsv` に「ことば<TAB>ひらがなの読み」を足して、make.pl を流す |
| 1文字（「は」「へ」など）の読みがちがう | `overrides.tsv` に「文<TAB>@カナ（アクセント記号 ' 付き）」を書く |
| アプリで ずんだもんの声にならない文がある | おとな向けに `localStorage` の `chiid-voice-dev` を `1` にして遊ぶと、音声がなかった文が `chiid-voice-miss` にたまる。その文を voice-lines.js に足す |
| タブレットで音が出ない | 端末の音量・マナーモードを確かめる。音声ファイルが鳴らせないときは、端末の声で読む |
