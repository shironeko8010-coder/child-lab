# 勉強アプリ（小2）「どうとく」 設計書（案）

作成日: 2026-11-10 / 対象: `app-benkyo/`
正本: `docs/design-spec.md`（全体）、`docs/superpowers/specs/2026-11-08-benkyo-kuku-design.md`（土台）。本書は教科「どうとく」の追加分だけを書く。
状態: **やまとさん承認済み（2026-11-10）**。A〜H・かんがえる問題を1区分ずつ確認し、直しを反映した。

## 1. 目的と範囲
- 「こんなとき どうする？」の場面を、絵と文で見せ、3つの中から選ぶ。声でも読む。
- ×は付けない。どれを選んでも、理由を返す。
  - 望ましいものを選んだら → ほめる（5問ごとに星）。
  - ほかを選んだら → やさしく理由を伝えて、もう一度えらべる（選んだボタンは うすく なるだけ。×や赤は使わない）。
- 正解のない「あなたなら どうする？」の **かんがえる もんだい** も入れる。どれを選んでも「そう かんがえたんだね」と受けとめ、「パパや ママと はなして みてね」で終わる。親子で話すきっかけにする。
- 内容は、知育の「どうとく」（あいさつ・ありがとう・ごめんね・じゅんばん・かして/どうぞ・おかたづけ・てあらい・あぶないこと）を深めたもの＋人としての常識（相手の気持ち、うそ・約束、公共のマナー、時間、電話、いのち・自然、ネットの約束）。
- 参考: 文部科学省 小学校学習指導要領「特別の教科 道徳」第1学年及び第2学年の内容項目（下の表の「内容項目」列）。
  - A 自分自身: 善悪の判断・自律・自由と責任／正直・誠実／節度・節制／個性の伸長／希望と勇気・努力と強い意志
  - B 人との関わり: 親切・思いやり／感謝／礼儀／友情・信頼
  - C 集団や社会: 規則の尊重／公正・公平・社会正義／勤労・公共の精神／家族愛・家庭生活の充実／よりよい学校生活・集団生活の充実／伝統と文化の尊重・国や郷土を愛する態度／国際理解・国際親善
  - D 生命や自然: 生命の尊さ／自然愛護／感動・畏敬の念
- 今回やらない: 自由に文を書く答え、場面の追加・編集を親画面から行う機能。

## 2. 1回の流れ（九九・けいさんと同じ区切り）
1. 1回＝10もん。そのうち **かんがえる もんだい を1〜2もん** まぜる（6もんめ・10もんめ あたり）。
2. 場面の絵＋文を出し、声で「（場面）。こんなとき どうする？」と読む。スピーカーボタンで もう一度きける。
3. 3つのボタン（文＋声）。ならびは毎回 入れかえる。
4. えらぶと、その答えへの返事を ぴよ（キャラクター）の ふきだしに出して 声で読む。
   - 望ましい答え: よろこぶ音＋ほめ言葉 → **声を言い終わってから** 少し待って次へ（「つぎへ」ボタンで早めに進むこともできる）。
   - ほかの答え: やさしい音（叱らない）＋理由＋「もういちど えらんで みよう」→ そのボタンを うすくして、のこりから えらべる。
   - かんがえる もんだい: どれを選んでも受けとめる返事＋「パパや ママと はなして みてね」。**自動では進まず**「つぎへ」を押して進む（ゆっくり考えられるように）。
5. 5もんごとに星。10もんで ごほうび画面（「よく かんがえたね！」・もういっかい／おわる）。
6. 問題と問題のあいだで利用時間を確かめる（`B.checkRest()`）。
- 出し方: まだ出ていない場面を優先 → 前にまちがえた（1回目でえらばなかった）場面 → そのほか。同じ回の中で同じ場面は出さない。レベル分けはしない（場面の むずかしさに差を付けない）。

## 3. 記録（端末内だけ）
| 種類 | area | itemId | correct |
|---|---|---|---|
| えらぶ もんだい | `doutoku_b` | 場面の名前（例「でんしゃの なか」） | 1回目で望ましい答えを選んだら true、それ以外 false |
| かんがえる もんだい | `doutoku_bk` | 場面の名前 | いつも true（「考えた」の記録） |

- 親画面の教科名: `doutoku_b: 'どうとく（べんきょう）'`、`doutoku_bk: 'どうとく（かんがえた）'`（知育の `doutoku` と区別する）。
- 親画面の「苦手」には、1回目で望ましい答えを選ばなかった場面の名前が出る → 親子で話すときの手がかりにする。

## 4. 文字とふりがな
- 文はひらがな中心・分かち書き（ことばの間に空白）。1年生の漢字（先生・学校・本・手・名・車・花・水 など）はそのまま使う。
- 2年生以上の漢字を使うときは、必ず ふりがな（`<ruby>`）を付ける。データでは `{電車|でんしゃ}` のように書き、画面は ruby に、声は よみ に直す。
- 下の一覧は、読みやすさのため ほぼ ひらがなで書いている（実装も この文で入れる）。

## 5. 絵（SVG＋CSS）
- 1場面1枚の絵を、部品の組み合わせで作る（33枚を1枚ずつ描かない）。
  - 背景: 学校／いえ／げんかん／こうえん／みち（しんごう）／でんしゃ／としょかん／おみせ／タブレット画面／花だん
  - 人: じぶん（こども）、ともだち、えまちゃん（妹・小さめ）、パパ、ママ、先生、おとしより、しらない人（帽子とサングラスではなく「?」マークの吹き出しで表す。こわく しない）
  - 小物: けしゴム、えんぴつ、ボール、クレヨン、おもちゃ、でんわ、ゲーム機、本、おかし、あり、花、ハンカチ、せっけん など
- 表情（にこにこ／こまった／ないている）を顔の線で変える。あぶない場面も、こわい絵にはしない。
- おみせ（25）は、パパや ママと一緒にいる絵にする（子どもだけで買い物をする前提にしない）。
