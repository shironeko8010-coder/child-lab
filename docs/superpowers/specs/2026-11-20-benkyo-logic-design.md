# 設計書：べんきょう「ロジックぬりえ」

## 1. 目的
- たて・よこの 数字を ヒントに マスを ぬると、絵が 出てくる パズル。小学2年生は 小さい 5×5 から、レベル4・5は 大人も 頭を つかって 楽しめる。
- 名前は「ロジックぬりえ」（「お絵かきロジック」は 商品名（登録商標）なので つかわない）。

## 2. 決めたこと（やまとさんと決めた）
| レベル | マス | 絵 | まちがえたとき |
|---|---|---|---|
| 1 | 5×5 | かんたんな 形（ハート・さかな など） | すぐ 知らせる |
| 2 | 5×5（形が 複雑） | ねこ・ロボット など | すぐ 知らせる |
| 3 | 7×7 | りんご・ロケット など | 最後に「こたえあわせ」 |
| 4 | 8×8 | どうぶつ・のりもの など | 最後に「こたえあわせ」 |
| 5 | 10×10（大人むけ） | きょうりゅう・くじら など | 最後に「こたえあわせ」 |
- 絵は 手で 作った ドット絵。1レベル 10まい、ぜんぶで 50まい（`app-benkyo/subjects/logic.js` の PICS）。
- どの絵も、答えが 1つだけで、当てずっぽう なしに とける（1列ずつ 決めていく とき方だけで ぜんぶ 決まる）。`tests/logic.test.js` で ぜんぶ しらべている。
- ボタン：ぬる・×（ぬらない しるし）・けす（3つの ばんを 切りかえる）、ヒント、こたえあわせ（レベル3〜5）。
- とけたら 絵に 色が つき、「できた！ ○○の えだよ！」→ ごほうび（1問ごと）。
- 記録の「正解」は、ヒント 0回、かつ、まちがい 1回 以下。
- レベルは 始めに えらべる（「つづき」か 1〜5）。結果で 自動に 上がり下がり。

## 3. 遊び方〔作る人の判断を ふくむ〕
1. マスを さわると、えらんで いる ばんで 変わる。
   - ぬる：ぬる（もう一度で もどす）
   - ×：× を つける（もう一度で もどす）
   - けす：まっさらに もどす
2. レベル1・2：ぬらない マスを ぬると すぐ 赤く して「そこは ぬらない マスだよ」。ぬる マスに × を つけると「そこは ぬる マスだよ」。どちらも まちがい 1回。ぬる マスが ぜんぶ ぬれて、まちがいの ぬりが なければ できた。
3. レベル3〜5：「こたえあわせ」で、ぬらない マスを ぬって いたら 赤く して「あかい マスを みなおそう」（まちがい 1回）。たりない だけなら「まだ ぬる マスが あるよ」（まちがいに しない）。× は しらべない（しるしだけ）。
4. ヒント：まちがって ぬった マスが あれば × に なおす。なければ ぬる マスを 1つ ぬる。
5. 数字の 列が ぴったり 合うと、その 数字は うすい 色に なる（できた 列が わかる）。
6. 10×10 は 5マスごとに 太い 線。
7. はじめの 説明：レベル1・2は 始めに「よこと たての 数字は、つづけて ぬる マスの 数だよ」と 言う。スピーカーの ボタンで もう一度 聞ける。

## 4. 記録
- `area: 'logic'`、`itemId: 'lv' + レベル`、1問1件。

## 5. 画面
- よこ向き：左に 表（上と 左に 数字）、右に ボタン。たて向き：上に 表、下に ボタン。スクロールなし（8つの 画面の 大きさ）。
- ボタンは 56px 以上（高さ 340px 以下の 画面では 48px 以上）。
- 〔作る人の判断：例外〕10×10 の マスは スマホで 24〜31px、数字の 字は 13〜17px（決まりの 56px・18px に できない）。タブレットでは マス 42px 以上。8×8 も スマホで マス 26〜37px。
