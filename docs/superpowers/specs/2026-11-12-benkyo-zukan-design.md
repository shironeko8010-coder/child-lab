# 設計書：べんきょう「ずかん」

> グレードアップ（まめちしき・3問目・スマホの2まい表示・テーマとページの追加）の設計書：`docs/superpowers/specs/2026-11-14-benkyo-zukan-upgrade-design.md`。ちがう所は そちらが正しい。

## 1. 目的
- 小学2年生が、図鑑を読むように「短い説明を読んで（聞いて）→ 問題に答える」ことで、いきもの・自然・からだ・のりものの知識を身につける。
- 正解するとカードが「わたしのずかん」に集まり、何度でも読み直せる。集める楽しさで続け、見直して覚える。
- 叱らない。まちがえてもカードはもらえる。

## 2. 画面の流れ
```
教科を選ぶ画面（計算・九九・漢字…・ずかん）
   └ ずかん を押す
      └ テーマ選びの画面（9テーマを 3×3）
          ├ テーマを押す → 図鑑のページ → 問題2問 → カード（3ページで ごほうび）
          └「わたしのずかん」ボタン → 集めたカードを見る・読み直す
```
- 「わたしのずかん」は、テーマ選びの画面からだけ開ける。

## 3. 1回の流れ
1. テーマを選ぶ。テーマのカードには「集めた数／12」と、きらきらの数を出す。
2. 図鑑のページ：絵と2〜3文の説明を出し、ずんだもんが読み上げる。「よめた！」ボタンで問題へ。もういちど きくボタンあり。
3. 問題を2問（4択）。説明に書いてあることから出す。
   - 1回目のまちがい →「もう{一回|いっかい} やってみよう！」。選んだボタンは うすくなる。
   - 2回目のまちがい → 正しいボタンを光らせ「こたえは｜<答え>｜だよ。｜つぎは できるよ！」。「つぎへ」で次へ。
4. 2問答えたら、そのページのカードがもらえる（まちがえても もらえる）。2問とも1回目で正解なら **きらきらカード**（金色のふち）。
5. 3ページで1回おわり。ごほうび画面（「もう{一回|いっかい}」「おわる」）。
6. 1日の利用時間を超えたら、次のページの前にお休み画面。

### ページの選び方
- そのテーマで、まだカードがないページ → きらきらでないページ → ぜんぶきらきらなら どれでも、の順に選ぶ。
- 同じ回で同じページは出さない。直前のページは出さない。

### 記録
- 1ページにつき1件。`area: 'zukan'`、`itemId: <ページのid>`、`correct`＝2問とも1回目で正解か。
- カードは記録から作る：記録が1件でもあれば カードあり、`correct: true` が1件でもあれば きらきら。
- 選択肢の並びは毎回まぜる。レベル分けはしない（きらきらにすることが、もう一段の目標）。

## 4. わたしのずかん
- 上にテーマのタブ（9つ）。選んだテーマの12ページをカードで並べる（横向き 6×2、たて向き 3×4）。
- 集めたカード：絵・名前。きらきらは金色のふち。押すと そのページ（絵・説明）を出し、読み上げる。「もどる」で一覧へ。
- まだのカード：「？」のシルエット。押しても何もしない。
- 「もどる」でテーマ選びの画面へ。

## 5. 教科を選ぶ画面
- 教科カード `{ id: 'zukan', name: 'ずかん', sub: 'よんで こたえよう', enabled: true }` を「はんたい ことば」のあと、「えい語」の前に足す（11まい）。アイコンは本の SVG。
- 横向きは 6まい×2段にする（今は 5まい×2段）。たて向きは 3まい×4段。

## 6. 画面の字と絵
- 画面の字：1年生の漢字はそのまま、2年生の漢字は `{漢字|よみ}`、3年生以上は ひらがな。いきもの・のりものの名前は カタカナ（図鑑と同じ）。
- 絵：Unicode 12 以前の絵文字。絵文字がないページ（★の11ページ）は、かんたんな SVG（形と色だけの絵）を作る。
- 説明は、図鑑や教科書に書いてあるような、はっきりした事実だけにする。
