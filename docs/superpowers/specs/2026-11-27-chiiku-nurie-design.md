# 設計書：ちいく「ぬりえ」

## 1. 目的
- 5歳の子が、線の絵に すきな色を ぬる。正解・不正解は ない。色の名前、自由な表現、指先の 動き。
- ぬったあと スタンプで 飾りつけして、作品として 残す。

## 2. 決めたこと（やまとさんと決めた、2026-11-27）
| 項目 | 内容 |
|---|---|
| はじめ | 線の絵（16まい）から すきな絵を えらぶ |
| 道具 | 「ぬる」（タッチした所の 線で かこまれた ぶぶんが 色で うまる）／「ふで」（指で 自由に 描く）／「スタンプ」（飾りつけ。タッチした所に ポンと 押す） |
| 色 | 12色。色を タッチすると 色の名前を 読む |
| スタンプ | 9こ：ほし・はーと・おはな・おんぷ・りぼん・にじ・きらきら・くも・おひさま。大きさは「ちいさい・ふつう・おおきい」の3つから えらべる（はじめは ふつう） |
| ボタン | 「ひとつ もどす」「ぜんぶ けす」「できた！」 |
| できた！ | キラキラと「すてきな えが できたね！」。作品は 端末の中に 保存 |
| 作品 | 「さくひん」で 見返せる。新しい 20まいまで（古いものから 消える） |
| 記録 | 親画面には「ぬりえ」として 1まい1件（正解・不正解は つけない。いつも true） |
| 1日の目安 | 1まい できた ところで、目安を こえていたら お休み（とちゅうでは 止めない） |
| 絵 | 線の絵・スタンプとも Figma の AI で 作る |

## 3. 作る人の判断
- 12色：あか・ももいろ・だいだい・きいろ・きみどり・みどり・みずいろ・あお・むらさき・ちゃいろ・くろ・しろ（しろは 消しゴムの かわりにも なる）。
- 「ぬる」は 線の絵だけを 見て 区切りを 決める（ふでで 描いた 線は 区切りに しない）。線の 内がわに 白い すき間が 残らないよう、線の下まで 2点ぶん ぬる。線の上を タッチしたら、いちばん近い ぬれる所を ぬる。
- スタンプの 大きさ：ちいさい 64・ふつう 104・おおきい 168（絵は 512）。大きさボタンは スタンプの 下に ならべ、丸の 大きさで 見分ける。
- 「ぜんぶ けす」は 確認しない（「ひとつ もどす」で もどせるため）。「ひとつ もどす」は 12回まで。
- 絵は 512×512。線の絵は 4だんかいの 灰色に して 小さくした。
- `index.html` を 直接 開いたときも「ぬる」が 使えるよう、線の絵と スタンプは `app-chiiku/nurie-data.js` に 文字（data URL）として 埋めこむ（ふつうの 画像ファイルは、点を 調べられない）。作り方：`archive/proto-src/nurie/cut.sh`・`make-data.sh`。
- 作品は localStorage（`chiid-nurie-<プロフィールid>`）に JPEG で 保存。保存できない（いっぱい）ときは 古いものから 消して やりなおす。

## 4. 画面
- えらぶ画面：絵を 8まいずつ ならべて ◀ ▶ で めくる。「さくひん」ボタン。
- ぬる画面（2026-11-27 やまとさんの希望で 変更：絵を できるだけ 大きく）：
  - 横向きは 上の帯を 使わず、おうち・おんがく（おんがく＝BGMの オン・オフ）は 右の列の いちばん上に 置く。ぬりえの ボタンは 右の列の 下に まとめ、間を あけて 押しまちがいを ふせぐ。たて向きは おうち・おんがくを 画面の 上に 置く。
  - ぬりえの ボタンは 大きめ（タブレットで 120×86px ほど。小さい 画面でも 56px 以上）。
  - 色と スタンプは 並べて 出さない。「いろ」ボタン（いまの 色の 丸）・「すたんぷ」ボタン（いまの スタンプ）を 押すと、えらぶ まどが 開く。えらぶと とじる（まわりを さわっても とじる）。スタンプの まどでは 大きさ（大・中・小）も えらべる。
  - 色を えらぶと、スタンプの ときは「ぬる」に もどる。「すたんぷ」を 押すと スタンプの 道具に なる。
  - 横向きは 左に 絵、右に 道具（2れつ）。たて向きは 上に 絵、下に 道具（2だん）。
- スクロールなし（8つの 画面の 大きさ）。ボタン 56px 以上（高さ 340px 以下は 48px）。

## 5. 読み上げ（新しく 作る）
