# 設計書：ちいく「めいろ」に「よる」と「まっくら」を足す

前の設計書：`docs/superpowers/specs/2026-11-14-chiiku-meiro-design.md`（めいろの作り方・レベル・ヒント・記録は そのまま。この設計書は 足すところだけ）

## 1. 目的
- 夜のイメージで めいろを暗くし、ひよこの まわりしか 道が見えないようにする。道を「さがす」むずかしさを足す（やまとさんの提案）。

## 2. 決めたこと（やまとさんと決めた）
| 点 | 決め |
|---|---|
| 暗さ | 全体を夜のように暗くする。ひよこの まわり 2マス（丸い明かり）だけ 道が見える |
| よる | ひよこの まわり 2マスだけ 見える。通ったマスには うすく光る「あしあと」が残る（2026-11-15 に、はじめの「まっくら」の決まりを よるに した） |
| まっくら | ひよこの いるマスと その まわり1マス（3×3の9マス）だけ 見える。あしあとは 残らない。目じるしは いつも見える（2026-11-15 に むずかしく した。むずかしすぎたら また変える） |
| 目じるし | ごはん・ほし・かぎ・とびら は、暗くても 光って 見える（どこへ行くかは 分かる） |
| 選び方 | めいろを始めるときに 絵のボタンで選ぶ：☀️ ひる／🌙 よる／🌑 まっくら（字が読めなくても選べる） |
| ヒント | 今と同じ（6秒 動かないと、光る道を見せる）。光る道は 暗い中でも見える |

## 3. 作る人の判断〔作る人の判断〕
- よるの「まわり2マス」は、マスの中心どうしの きょりが 2 以下のマス（たて・よこ2マスと ななめ1マス。ぜんぶで13マスの 丸っぽい形）。壁の向こうでも 見える（5歳には 壁で さえぎると むずかしすぎるため）。
- 選ぶ画面は めいろを開いたとき（ホームのカードを さわったとき）に出す。ごほうびのあと「つぎへ」では 同じ選び方のまま続ける。
- 選んだら、よる・まっくら は ひとこと言ってから めいろを始める：
  - よる「よるの めいろだよ。ちかくしか みえないよ」
  - まっくら「まっくらの めいろだよ。ひよこの まわりしか みえないよ」
- 選ぶ画面の声：「どれで あそぶ？」（トップと同じ音声ファイル）。
- 記録・レベルの上がり下がりは 今と同じ（ひる・よる・まっくら を分けない）。むずかしさの ちがいは 子どもが選ぶ。
- テストのページ（画面なし）で モードを指定しないで始めたときは「ひる」で すぐ始める（今のテストを そのまま使うため）。

## 4. 見た目
- 暗さ：めいろの上に こい紺色（#0d1430、不透明度 .93）を かぶせ、明るい所だけ 穴をあける（SVG のマスク）。
- よる：明るい所＝ いまの まわり2マス。通ったマスは うすく（.45）明るい。
- まっくら：明るい所＝ いまの まわり1マス（9マス）。通ったマスは 暗いまま。
- 目じるし（ごはん・ほし・かぎ・とびら）と ひよこ・ヒントの道 は マスクの上に描く（光って見える）。
- 選ぶ画面：大きな ボタン3つ（絵＋ひらがな）。スクロールなし（8つの画面の大きさ）、ボタン 56px 以上。

## 5. テスト
- `litCells(maze, at, visited, mode)`：ひる＝null（ぜんぶ明るい）、よる＝いまの まわり2マスは1・通ったマスは .5、まっくら＝いまの まわり1マス（9マス）だけ1。
- まわり2マスの形（半径の中のマスの数＝13、角では少ない）。
- start(PID, 'night') で モードが入る。動くと 明るい所が ふえる（よる）／ふえない（まっくら）。
- start(PID) は ひる（今のテスト）。
- 読み上げ文が すべて音声ファイルにある（新しい2文）。
