# 勉強アプリ（小2）「けいさん」（たし算・ひき算） 設計書

作成日: 2026-11-09 / 対象: `app-benkyo/`
正本: `docs/design-spec.md`（全体）、`docs/superpowers/specs/2026-11-08-benkyo-kuku-design.md`（土台と九九）。本書は教科「けいさん」の追加分だけを書く。

## 1. 目的と範囲
- 小2のお子さんが、親なしで、たし算・ひき算を練習できる。苦手な式が親画面で分かる。
- 作りは九九と同じ（数字ボタン、2回目でこたえを見せる、10問で区切り、5問ごとに星、問題のあいだで利用時間の確認）。
- 今回やらない: 筆算（たての式）の表示、文章題、3つの数の計算。

## 2. レベル（おすすめ案：くり上がり・くり下がりの段階で分ける）
1桁同士から始め、2桁、くり上がり・くり下がり、答えが100をこえる計算へ進む。

| レベル | 内容 | 例 |
|---|---|---|
| 1 | たし算 1桁＋1桁（くり上がりなし、答え9まで） | 3 + 4 |
| 2 | ひき算 1桁−1桁（答え0以上） | 8 − 3 |
| 3 | たし算 1桁＋1桁（くり上がりあり、答え10〜18） | 7 + 8 |
| 4 | ひき算 十いくつ−1桁（くり下がりあり） | 15 − 7 |
| 5 | 2桁の たし算・ひき算（くり上がり・くり下がりなし） | 23 + 45、68 − 25 |
| 6 | 2桁＋2桁（くり上がりあり、答え99まで） | 38 + 47 |
| 7 | 2桁−2桁（くり下がりあり） | 72 − 38 |
| 8 | 答えが100をこえる たし算／百いくつ−2桁 | 67 + 58、134 − 68 |

- 進み方は九九と同じ（共通の `adaptive`）：直近5問で4問以上正解で1つ上、2問以下で1つ下。レベルは記録から毎回組み立てる。
- 間違えた式は「苦手」として記録し、同じレベルの出題で多めに出す（3回に1回くらい、苦手の中から重みつきで選ぶ）。直前と同じ式は出さない。
- 答えは最大3桁（レベル8）なので、数字ボタンの入力は3桁まで。

## 3. 画面と声
- 「23 + 45 = ?」を大きく表示（九九と同じ横の式）。声で「23 たす 45 は？」「45 ひく 23 は？」と読む（数字は合成音声が「にじゅうさん」と読む）。
- 間違えた時: 1回目「もういっかい やってみよう！」、2回目「こたえは 68 だよ。つぎは できるよ！」で次へ。空のまま「こたえる」は数えない。
- トップのカード名は「けいさん」、下に「たしざん・ひきざん」（ひらがなのみ）。
- 九九の「だんを えらぶ」に当たる選択は、今回は付けない（じどうのみ）。必要なら次に「たしざんだけ／ひきざんだけ」を足せる作りにする。

## 4. 記録
- 1問1件。area=`keisan`、itemId は式（例 `23+45`、`72-38`）、正誤、レベル。九九と同じ `Chiid.storage.logAnswer`。端末内だけ。
- 親画面の教科名に `keisan: 'けいさん'` を足す。

## 5. ファイル
| ファイル | 内容 |
|---|---|
| `app-benkyo/subjects/keisan.js` | `Chiid.keisan`：レベルごとの出題、判定、記録からレベル・苦手を組み立てる（画面に触らない） |
| `app-benkyo/keisan-screen.js` | `Chiid.benkyo.keisanScreen`：問題画面とごほうび画面（九九の画面と同じ見た目・部品） |
| `app-benkyo/main.js` | SUBJECTS の `keisan` を有効にし、開く処理を足す |
| `app-benkyo/index.html`、`sw.js` | スクリプトとキャッシュに追加、`CACHE_NAME` を上げる |
| `shared/parent.js` | 教科名を1つ追加 |
| `tests/keisan.test.js`、`tests/index.html`、`tests/benkyo.test.js` | テストの追加と、教科一覧テストの更新 |

## 6. 確認
- 自動テスト: レベルごとの範囲（くり上がりの有無、答えの範囲、ひき算が負にならない）、判定、2回間違いの流れ、空入力、レベルの上下、記録、教科一覧。既存テストを壊さない。
- 画面: 1280×800、714×321（スマホ横）、390×780（縦）で見切れなし。
- 実機（やまとさん）: 3桁の入力、声の読み方、押しやすさ。
