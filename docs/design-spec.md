# 設計書：子ども向け学習アプリ（試作フェーズ）

## 1. 範囲
- 共通基盤（保存、音声、効果音、おとなゲート、親画面の骨組み）
- 知育アプリ（5歳）：ひらがな学習のミニゲーム1つ
- ブラウザで開いてオフラインで動く。Androidタブレット横向きを想定。
- 九九・漢字・英語は、試作の土台を確認してから追加する。

## 2. 技術
| 項目 | 内容 |
|---|---|
| 作り方 | 素のHTML/JS/CSS、ビルド不要、通常の `<script>` 読み込み |
| 保存 | localStorage（設定）＋IndexedDB（学習ログ） |
| 音声読み上げ | VOICEVOX:ずんだもん の音声ファイル（`voice/z/`）。ファイルがない文は Web Speech API（端末の日本語音声）。詳しくは `docs/superpowers/specs/2026-11-11-voice-zundamon-design.md` |
| 効果音・BGM | WebAudio で合成 |
| イラスト | SVG + CSSアニメーション |
| オフライン | Service Worker + manifest.json |
| なぞり書き判定 | 薄い文字に重なる割合で判定（書き順は判定しない） |

## 3. フォルダ構成

## 4. ひらがなミニゲーム「おとをきいて、なぞろう」
1. キャラクターが文字を読み上げる
2. 3択の絵カードから選ぶ（例：「あ」→あり）
3. 大きな文字を指でなぞる
4. 成功で星と音のごほうび。失敗は励ます。
対象文字：あ行〜か行の10文字から開始。正答率で出題を調整する。

## 5. 役割と完了条件
| 役割 | 完了条件 |
|---|---|
| 教育設計 | 文字の順番・出題・難易度・ごほうびの設計が1枚にまとまる |
| UI/UX | 画面の流れ・配色・キャラクターSVG・アニメーション案がそろう |
| 実装A（土台） | shared の各部品が単体で動き、オフラインで開ける |
| 実装B（ひらがな） | 土台を使って最後まで遊べる |
| QA | 下記チェックがすべて合格 |

並列：土台のインターフェースを先に決め、教育設計・UI/UX・実装Aを同時に進める。その後に実装B、最後にQA。

## 6. QAチェック
- 通信が1件も出ていない
- 機内モードで動く
- おとなゲートなしで親画面に入れない
- 園児用の画面がひらがなだけ
- 叱る表現がない
- タブレット横向きでボタンが十分大きい
- 親画面で、記録の確認・書き出し・リセットができる

## 7. 未確認・制約
- Android実機での確認は、やまとさんに依頼する。
- 名前が入る文など、音声ファイルがない文だけ、端末の声で読む（声は端末ごとに違う）。
- 公開場所（オフライン・アプリ化の確認用）は、後で相談する。
