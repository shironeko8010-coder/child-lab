# 勉強アプリ（小2）「せかいの 国」 設計書（案）

作成日: 2026-11-11 / 対象: `app-benkyo/`
正本: `docs/design-spec.md`（全体）、`docs/superpowers/specs/2026-11-08-benkyo-kuku-design.md`（土台）。本書は教科「せかいの 国」の追加分だけを書く。
状態: **やまとさん承認済み（2026-11-11）**。模様の細かい国旗は「細かいところを省いて描く」案を採用。大陸は六大陸、韓国はレベル1、ペルーはふだん使う旗。

## 1. 目的と範囲
- 国旗と世界地図で、世界の国の名前・場所・大陸を楽しく覚える。親なしで遊べる。
- 国旗も世界地図も、すべて自分で SVG（線で描く絵の形式）で描く。絵文字の国旗は使わない（Windows で出ないことがあるため）。通信なし。
- 今回やらない: 国の首都・人口などの知識問題、地図を指でタップして答える問題、あつめた国の図鑑。

## 2. ホームのカード
| 項目 | 内容 |
|---|---|
| id | `chizuW` |
| 名前 | `せかいの {国|くに}`（「世界」は3年生の字なので ひらがな。「国」は2年生の字なので ふりがな） |
| 下の小さい文字 | `{国|こっ}きと ちず` |
| 記録の area | `chizuW`（親画面の教科名: `chizuW: 'せかいの国'`） |

## 3. 問題の種類（どれも3〜4択。叱らない）
| # | 種類 | 画面 | 声 | 出るレベル |
|---|---|---|---|---|
| 1 | 国旗あて | 国旗を大きく1枚 → 国名ボタン | 「この 国旗は どこの 国？」 | 1〜 |
| 2 | 国旗えらび | 「フランスの 国旗は どれ？」→ 国旗ボタン | 同じ文 | 1〜 |
| 3 | 地図で国 | 地図で1か国が光る → 国名ボタン | 「ひかって いる 国は どこ？」 | 1〜 |
| 4 | 大陸あて | 地図で大陸が光る → 大陸名ボタン | 「ひかって いる 大りくは どこ？」 | 2〜 |

- えらぶ数: レベル1は3択、レベル2・3は4択。ボタンのならびは毎回入れかえる。
- 正解したら: よろこぶ音＋「せいかい！」→ 地図がその国の大陸まで寄って、**その国が色づき**、ひとこと説明（例「フランスは エッフェルとうが ある 国だよ」）を出して声で読む → 読み終わって少し待って次へ（「つぎへ」で早めに進める）。
- まちがえたら: やさしい音＋「もういっかい やってみよう！」。押したボタンはうすくなるだけ（×や赤は使わない）。2回まちがえたら、正解を光らせて「こたえは フランスだよ。つぎは わかるよ！」→ 色づき＋ひとこと説明 → 次へ。
- 1回＝10もん。5もんごとに星。10もんで ごほうび画面（もういっかい／おわる）。問題のあいだで利用時間を確かめる（`B.checkRest()`）。
- 国旗の問題は、★（かんたんに描く国旗）の国をレベル3になるまで出さない。

## 4. レベル（自動で上がる）
| レベル | 国の数 | 問題 |
|---|---|---|
| 1 | 10か国（有名な国） | 1・2・3（3択） |
| 2 | 20か国（レベル1＋10） | 1・2・3・4（4択） |
| 3 | 36か国（レベル2＋16） | 1・2・3・4（4択） |

- 進み方は九九と同じ共通の `Chiid.adaptive`：直近5問で4問以上正解（1回目で）なら1つ上、2問以下なら1つ下。レベルは記録から毎回組み立てる。
- 出し方: そのレベルの国から、まちがえた回数で重みを付けて選ぶ（`pickWeighted`）。同じ回の中で同じ国・同じ種類の組み合わせは出さない。直前と同じ国は出さない。
- まちがいの選択肢: 同じレベルの国から選ぶ。国旗えらびでは、色の並びが同じになる国旗どうし（例: インドネシアとモナコのような組）は入れない（今回の一覧には該当なし）。

## 5. 記録（端末内だけ）

|---|---|---|---|

## 6. 世界地図（SVG）
- 経度・緯度をそのまま横・縦にした地図（正距円筒図法）に、大陸と問題に出す国の **おおまかな形**（数十点の多角形）を描く。ほかの国は大陸の色のまま（国境線は出す国だけ）。
- 大陸ごとに寄る: 問題や正解の表示では、その国の地域（アジア・ヨーロッパ・アフリカ・北アメリカ・南アメリカ・オセアニア）まで自動で拡大する（SVG の `viewBox` を切り替えるだけ。絵は1枚）。
- 小さい国（スイス・オランダ・韓国 など）は、拡大しても小さいので、**国のまわりに光る丸** を重ねて場所を分かりやすくする。
- 答えはボタンで選ぶので、地図を指で押す必要はない（小さい国が押しにくい問題は起きない）。
- 南極は地図の下に横長に描く（大陸あて用）。
- 大陸あてでは、国の色を消して線だけにする（大陸全体の色が見えるように）。
- 色: 海はうすい水色、陸はうすいベージュ、光る国は黄色の点滅、正解した国は緑。

## 7. 国旗（SVG）
- 1か国1つの SVG を、正式な比率（縦:横）と色で描く。色は各国の公式指定に近い値を使う。
- 模様が複雑な国旗（紋章・文字・細かい絵が入るもの）は、**細かいところを省いて描く**（下の一覧「★かんたんに描く」）。本物と少し違うことは承知のうえ。色・比率・大きな形（帯・ひし形・円など）は本物に合わせる。
- ★の国旗は **レベル3からだけ** 国旗の問題に出す（レベル1・2には入れない）。ブラジル・エジプトはレベル2では地図の問題だけに出る。
- 星・十字・車輪・太陽などの幾何学的な模様は、正式な作図（位置・大きさ）に合わせて描く。
- 画面で本物と見比べて確かめる（実装後のQA）。

- 画面: 1280×800・714×321・390×780 で、国旗あて・国旗えらび・地図で国・大陸あて・こたえを見せる表示を確認し、見切れなし（スクロールなし）。

- 申し送り: ホームのカードが7枚（日本の地図を足すと8枚）になり、1280×800 では「えい語（じゅんび中）」が3段目に下がって、ホームが少しスクロールする。カードの並べ方（4列にする等）は、まとめるときに決める。
