# 知育「いろ・かたち」ゲーム 設計（2026-11-10）

## 目的
5歳の子が、声と文で「あかい まる は どれ？」と聞かれ、色つきの形のカードから えらぶ。親なしで遊べる。「かず」「とけい」と同じ流れ・同じ見た目。

## 画面
- 上：キャラ＋ふきだし「あか は どれ？」など（読み上げ。🔊ボタンで もういちど）
- 下：SVG（図形で描く絵）の 色つきの形カードを 3〜4枚。カードに文字は出さない（答えがわかってしまうため）。
- 正解 → 「せいかい！ あかい まる だね」＋星。5問ごとに「すごい！」画面。
- まちがい → 「おしい！ もういっかい えらんでみよう」（叱らない）。もう一度えらべる。

## つかう色と形

| いろ（よみ） | 色 | | かたち |
|---|---|---|---|
| あか | 朱色に近い赤 #FF4B00 | | まる |
| あお | 青 #005AFF | | さんかく |
| きいろ | 黄 #FFD400 | | しかく |
| みどり | 青みの緑 #03AF7A | | ほし |

- 色は「カラーユニバーサルデザイン推奨配色」（色の見え方が違う人にも見分けやすい色の組み合わせ）をもとにする。
- **あか と みどり は、同じ問題の選択肢に いっしょに出さない**（いちばん見分けにくい組み合わせのため）。
- 形には 濃い ふちどりをつける（きいろが白い背景に とけないように）。色だけでなく形でも区別できる。
- ピンク・オレンジなど カタカナの色名は使わない（園児用は ひらがなだけ）。

## レベル（自動で上下。「かず」「とけい」と同じしくみ：5問中の正解数で変わる）

| レベル | 問題 | 選択肢 | 例 |
|---|---|---|---|
| 1 | いろ だけ／かたち だけ（交互にランダム）。ほかの要素は そろえる | 3たく | 「あお は どれ？」→ 3つとも まる で色ちがい |
| 2 | いろ だけ／かたち だけ。ほかの要素は ばらばら（まどわせる） | 3たく | 「さんかく は どれ？」→ 色も形も ばらばら |
| 3 | いろ＋かたち の くみあわせ | 4たく | 「あかい まる は どれ？」→ あかい まる／あかい さんかく／あおい まる／きいろい しかく |

- レベル3は「同じ色で ちがう形」「同じ形で ちがう色」を必ず混ぜて、両方を見る練習にする。
- 選択肢は重ならない。こたえは必ず入る。

## 読み上げ・文
- いろ：「あか は どれ？」　かたち：「まる は どれ？」
- くみあわせ：「あかい まる」「あおい さんかく」「きいろい しかく」「みどりの ほし」

## 記録
- area `iro`。itemId は `aka`（いろ）、`maru`（かたち）、`aka-maru`（くみあわせ）の形。苦手なものは多めに出す（`missCounts`）。
- 親画面の表示名は「いろ・かたち」。

## 作り（技術メモ）
- `app-chiiku/iro.js` に `Chiid.iro`。`levelConfig`・`pickItem`（出題）・`makeChoices`（選択肢）・`question`（文）・`progressFromLogs` は純粋関数にしてテストする。形は `shapeSvg` でSVG文字列を作る。
- 画面部品は `Chiid.chiikuUi`（game.js）を使う。
- ホームのボタンが最終的に5つ（ひらがな・かず・とけい・まちがいさがし・いろ・かたち）になっても、3サイズ（1280×800／714×321／390×780）で見切れないよう `app.css` を調整（並べきれないときは2段）。
- `sw.js` の PRECACHE に追加し CACHE_NAME を上げる。テスト `tests/iro.test.js`。
