# 設計書：べんきょう「長さ・かさ」

## 1. 目的
- 小学2年生が、親なしで「長さ（mm・cm・m）」と「かさ（mL・dL・L）」を練習する。
- 目もりを読める、単位どうしの関係（1cm＝10mm、1m＝100cm、1L＝10dL、1dL＝100mL、1L＝1000mL）がわかる、ものに合う単位を選べる。
- 叱らない。2回まちがえたら答えを見せて、次へ進む。

## 2. 問題の種類
| 種類 | id | 画面 | 答え方 |
|---|---|---|---|
| 目もりを読む（長さ） | `readLen` | ものさしの上にテープ。左はしは 0 にそろえる | 数字ボタンで「□cm」または「□cm □mm」 |
| 目もりを読む（かさ） | `readVol` | 1Lます（10dL の目もり）に水。満タンのますを並べて L を表す | 数字ボタンで「□dL」または「□L □dL」 |
| 単位をかえる | `convert` | 「3cm5mm ＝ □mm」のような式 | 数字ボタンで、箱1つか2つ |
| 単位をえらぶ | `unit` | 「えんぴつの {長|なが}さ　15□」 | 単位のボタン（2〜3こ）から1つ |

## 3. レベル
| レベル | readLen | readVol | convert | unit |
|---|---|---|---|---|
| 1 | 1〜15cm（ちょうど） | 1〜9dL | 出さない | 出さない |
| 2 | 1cm1mm〜14cm9mm（mm は 1〜9） | 1L1dL〜3L9dL（dL は 1〜9） | cm⇔mm（XcmYmm→mm、X 1〜15・Y 0〜9／11〜159mm→□cm□mm）、L⇔dL（XLYdL→dL、X 1〜3・Y 0〜9／11〜39dL→□L□dL） | cm・mm／L・dL |
| 3 | レベル2と同じ | レベル2と同じ | レベル2に加えて m⇔cm（XmYcm→cm、X 1〜3・Y 0〜99／101〜399cm→□m□cm）、mL（XdL→mL、X 1〜9／XL→mL、X 1〜3／100〜900mL→dL） | m・cm・mm／L・dL・mL |

- 1回の練習は10問。長さとかさをまぜる。レベル2・3は、4種類をできるだけ同じくらい出す（レベル1は readLen と readVol だけ）。
- レベルの上がり下がりは、今の教科と同じ `C.adaptive.nextLevel`（最高 3）。まちがえた問題の id を重く出す（`C.adaptive.pickWeighted`）。
- 問題の id の形：`readLen:35`（mm で表した長さ）、`readVol:13`（dL）、`convert:cm-mm:35`、`unit:enpitsu` など。記録は `area: 'nagasa'`。

## 4. 単位をえらぶ問題のもの
| id | 画面の文 | 数 | 正しい単位 | 出るレベル |
|---|---|---|---|---|
| enpitsu | えんぴつの {長|なが}さ | 15 | cm | 2・3 |
| note | ノートの よこの {長|なが}さ | 18 | cm | 2・3 |
| ari | ありの {長|なが}さ | 5 | mm | 2・3 |
| ichien | 1円玉の あつさ | 1 | mm | 2・3 |
| pool | プールの {長|なが}さ | 25 | m | 3 |
| kokuban | こくばんの よこの {長|なが}さ | 4 | m | 3 |
| bucket | バケツに 入る 水 | 8 | L | 2・3 |
| gyunyu | ぎゅうにゅうパックに 入る ぎゅうにゅう | 1 | L | 2・3 |
| cup | コップに 入る 水 | 2 | dL | 2・3 |
| suito | 水とうに 入る お{茶|ちゃ} | 6 | dL | 2・3 |
| petto | ペットボトルに 入る 水 | 500 | mL | 3 |

- 単位のボタン：長さのものはレベル2なら cm・mm、レベル3なら m・cm・mm。かさのものはレベル2なら L・dL、レベル3なら L・dL・mL。

## 5. 答えたあと
- せいかい → 効果音・「せいかい！」。次の問題へ。
- 1回目のまちがい → 「もういっかい、やってみよう！」。入れた数字は消して、もう一度。
- 2回目のまちがい → 答えを見せる。ものさし・ますの答えの目もりを光らせ、箱に正しい数字を入れて、「こたえは｜<答え>｜だよ。｜つぎは できるよ！」と読む。次へ進むボタン。
- 記録は1問に1回。1回目でせいかいなら true。
- 5問ごとに星。10問でごほうび画面（今の「九九」と同じ）。1日の利用時間を超えたら、次の問題の前にお休み画面。

## 6. 画面
- 教科カード：`{ id: 'nagasa', name: '{長|なが}さ・かさ', sub: 'ものさし・ます', enabled: true }`。アイコンは ものさしの絵（SVG）。
- 左（または上）に絵、右に答えの箱と数字ボタン（「九九」「計算」と同じ `kk-pad`、「けす」「{答|こた}える」）。
- 箱が2つの問題は、タップした箱に数字が入る。はじめは左の箱。
- ものさし：0〜15cm、1cm ごとに数字、5mm に中くらいの線、1mm に短い線。テープはものさしの上。
- ます：1Lます（目もり 10）。満タンのますを左に並べ、最後のますに dL の水。readVol レベル1は、1つのますに 1〜9dL。
- 単位の文字は「cm・mm・m・L・dL・mL」（教科書と同じ）。

## 7. 読み上げ（ずんだもんの音声ファイル）
画面の単位は記号のまま、読み上げは カタカナ（センチ・ミリ・メートル・リットル・デシリットル・ミリリットル）にする。「は」で始まる部品は作らない（「は」だけだと「ハ」と読むため）。

| 文 | 部品の形 |
|---|---|
| readLen | 「テープの {長|なが}さは なんセンチ？」／「テープの {長|なが}さは なんセンチ なんミリ？」 |
| readVol | 「水の かさは なんデシリットル？」／「水の かさは なんリットル なんデシリットル？」 |
| convert | 「<数と単位>｜<数と単位>｜を ミリで いうと？」のように、数と単位の部品＋「を 〇〇で いうと？」 |
| unit | 「<ものの文>｜<数>｜どの たんいかな？」 |
| 答えを見せる | 「こたえは｜<数と単位>｜<数と単位>｜だよ。｜つぎは できるよ！」 |
| ほか | 「せいかい！」「もういっかい、やってみよう！」（今ある音声）、ごほうびの文は「九九」と同じ |

- 数と単位の部品：「Nセンチ」（N 0〜399）、「Nミリ」（0〜159）、「Nメートル」（1〜3）、「Nリットル」（1〜3）、「Nデシリットル」（0〜39）、「Nミリリットル」（100〜900・1000・2000・3000）、「N」（単位をえらぶ問題の数）。
- `tools/voice-lines.js` に作り方を足す。`make.pl --preview` と `check.pl` で、単位の読み（「センチ」「デシリットル」）、「を」で始まる部品の読み、数の読みを確かめてから作る。
- 文の数は約1,000の見込み（作るのに約40分）。

`C.nagasa` が外に出すもの：
- `AREA`（'nagasa'）、`MAX_LEVEL`（3）、`ROUND_SIZE`（10）、`STAR_EVERY`（5）、`UNIT_ITEMS`（4章）
- `kindsFor(level)` → そのレベルの種類の配列
- `idsFor(level)` → そのレベルで出せる問題の id の配列
- `makeQuestion(id)` → `{ id, kind, level?, boxes: [{ unit }], answer: [数…] , choices?: [単位…], show: {…絵に使う値} }`
- `pickQuestion(opts, rng)` → `opts = { level, missCounts, lastId, kindCounts }`
- `check(q, input)` → true / false（`input` は数の配列、unit は単位の文字）
- `speakText(q)`、`answerText(q)` → 7章の形の文
- `progressFromLogs(logs)` → `{ level, recent, missCounts }`

## 9. テスト
- `kindsFor`：レベル1は readLen・readVol だけ。レベル2・3は4種類。
- `idsFor` と `makeQuestion`：どの id も、レベルの範囲（3章）に入る。readLen レベル1は 1〜15cm、レベル2は mm が 1〜9。convert の答えが正しい（3cm5mm→35、159mm→15cm9mm、1m20cm→120、2L→2000mL、300mL→3dL）。
- unit：ものごとの正しい単位、ボタンの単位がレベルどおり（レベル2に m・mL が出ない）。
- `check`：正しい・ちがう。箱が2つの問題で、片方だけ合っているのは ちがう。
- `speakText`・`answerText`：部品の形。「は」で始まる部品がない。読み上げ文がすべて音声ファイルにある（今の「すべて音声ファイルがある」テスト）。
- `progressFromLogs`：area が nagasa だけを数える。
- 親画面に「ながさ・かさ」、教科カードに nagasa がある。
- 画面（ブラウザで確かめる）：1回目のまちがいでやり直し、2回目で答えが光る。記録が1問1件。10問でごほうび。1024×600 ではみ出さない。
- 実機（Androidタブレット）での操作・読み上げは、やまとさんに確かめてもらう。
