# 設計書：べんきょう「えい語」と、べんきょうのトップの2ページ化

## 1. 目的
- 小2の子が、親なしで、英語の音を聞いてわかる力（きく）と、アルファベットが読める力（よむ）をつける。
- 「自分で言う」練習は作らない（やまとさんの決定。声を聞き取る機能は通信が必要で、このアプリの決まりに合わないため）。
- 叱らない。間違えても、正しい答えを見せて、もう一度英語を聞かせる。

## 2. 決めたこと（やまとさんと決めた）
| 項目 | 決めたこと |
|---|---|
| 遊び | 「きく」と「よむ」の2つ。英語の画面に入ると、どちらで遊ぶか選ぶ |
| 英語の声 | 端末に入っている英語の読み上げの声（通信しない声だけ）。速さ 0.8。声は端末が最初に選ぶもの（アメリカ英語を優先）。ためしページ `app-benkyo/eigo-koe-test.html` で、やまとさんのタブレットで声が出て聞きやすいことを確認済み |
| 日本語の説明 | 今までどおり ずんだもんの音声ファイル |
| ことば | 12テーマ・約120こ（5章）。最初にテーマを選ぶ（「ぜんぶ」もある） |
| 作り方 | 今の教科と同じ形（ことば・問題のファイルと画面のファイルに分ける）。英語の声は新しい部品 `shared/voice-en.js` にまとめ、今の `voice.js` はさわらない |
| トップ | べんきょうのトップを2ページにする（ちいくと同じ形） |

### 考えた作り方（Approaches）
| 案 | 中身 | 決め |
|---|---|---|
| 1 今の教科と同じ形＋英語の声の部品を新しく作る | 今の日本語の声に手を入れない。テストしやすい | **採用** |
| 2 今の `voice.js` に英語を足す | 部品は増えないが、全教科の読み上げに影響するおそれ | 不採用 |
| 3 「きく」「よむ」を別の教科（カード2まい）にする | 画面は単純だが、カードが12まいになり、英語がばらばらに見える | 不採用 |

声の出し方で考えたもの：端末の英語の声（採用）／パソコンで音声ファイルを作る（このパソコンには英語の声が入っておらず、作るには やまとさんの作業が要るため不採用）／ずんだもんのカタカナ英語（発音が正しくないため不採用）。

## 3. 遊び方（1回の流れ）
1. べんきょうのトップで「えい語」を押す → 「きく」「よむ」の2つの大きなボタン（ずんだもん「どっちで あそぶ？」）。
2. きく：テーマを選ぶ（12テーマ＋「ABC」＋「ぜんぶ」）→ 問題。
   よむ：テーマを選ぶ（12テーマ＋「ぜんぶ」）→ 問題。
3. 1回は10問。5問ごとに ほしが1つ。10問で ごほうび画面（はんたい ことばと同じ形）。

（2026-11-14 変更：やまとさんと決めた）「きく」は耳だけ、「よむ」は目だけで分ける。前の「よむ」（アルファベットの文字の問題）は、文字の名前・ことばを聞いて文字を選ぶ問題を「きく」の「ABC」テーマに移し、「大文字を見て小文字を選ぶ（声なし）」は なくした。

### きく
- 問題が出ると、英語の声でことばを言う（例「dog」）。画面には絵のカード（3〜4まい）。英語の字は出さない（聞いてわかる練習のため）。
- 「もういちど きく」ボタン（スピーカーの絵）で、何度でも英語を聞ける。
- 正しいカード：正解の効果音、カードの下に英語のつづりを大きく出し、もう一度英語で言う。少しして次の問題。
- まちがい：そのカードをうすくする。ずんだもん「もういっかい きいてみよう」→ 英語をもう一度言う。
- 2回まちがえたら：正しいカードを光らせ、つづりを出し、英語で言う。ずんだもん「ひかっている ものだよ」。
- 1問の「せいかい」は、1回目で正しいカードを押したとき。

### きく の「ABC」テーマ（文字を聞いて選ぶ）
| レベル（きく のレベル） | 問題 | えらぶもの |
|---|---|---|
| 1 | 英語の声で 文字の名前（例「B」）を言う | 大文字 4つ |
| 2 | 英語の声で 文字の名前を言う（読み方は大文字と同じ「ビー」） | 小文字 4つ |
| 3 | 英語の声で ことばを言う（例「apple」。絵は出さない） | ことばの最初の文字（小文字）4つ |

- 「ぜんぶ」にも ABC を入れる（やまとさんの決定）。「ぜんぶ」の1問ごとに、ことば126こと文字26この中から えらぶのと同じ割合（だいたい6問に1問）で ABC の問題にする。〔割合は作る人の判断〕
- まちがい・2回まちがえたとき・「せいかい」の数え方は ことばの問題と同じ。正解のあと、その文字（またはことば）を英語でもう一度言う。

### よむ（つづりを見て、意味の絵を選ぶ）
- 問題が出ると、英語のつづりを大きく出す（例「dog」）。声は出さない（読んでわかる練習のため）。画面には絵のカード（3〜4まい）。
- 正しいカード：正解の効果音、カードの下に日本語の意味を出し、英語で読む（つづりと音をつなげる）。
- まちがい：そのカードをうすくする。ずんだもん「もういっかい よんでみよう」（英語は読まない）。
- 2回まちがえたら：正しいカードを光らせ、英語で読む。ずんだもん「ひかっている ものだよ」。
- 「せいかい」の数え方は「きく」と同じ。英語の声がない端末でも、全部遊べる（答えのあとの英語は鳴らない）。

## 4. レベル
### きく
| レベル | カード | まちがいのカード |
|---|---|---|
| 1 | 3まい | 同じテーマから |
| 2 | 4まい | 同じテーマから |
| 3 | 4まい | 答えと同じ文字で始まることばを できれば2まい（どのテーマからでもよい。足りなければ同じテーマ） |

- 「ぜんぶ」のときは、答えを全テーマから選び、まちがいのカードは答えのテーマから選ぶ（レベル3の「同じ文字で始まる」は どのテーマからでも）。
- 同じ回（10問）で、同じことばは2回出さない（テーマのことばが10こより少ないときは、すべて出たら くり返してよい）。
- 間違えたことばを多めに出す（今の教科と同じ `C.adaptive.pickWeighted`）。

- 絵文字のことばと、SVG で描くことば（いろ・かず・かたち）は、同じ問題のカードに まざってよい。どのことばの絵も ほかと重ならない（いろの丸・数字・形も ふくめて）。〔作る人の判断〕
- テーマのことばが カードの数より少ないことはない（いちばん少ない あいさつで7こ）。レベル3の「同じ文字で始まる」ことばが足りないときは、同じテーマから足す。

### きく の ABC
- まちがいの文字：レベル2・3は、まぎらわしい文字（b・d・p・q、m・n、u・n、i・l・j、c・o・e）があれば1つ入れる。
- レベル3のことば：1語のことば（スペースのないもの）だけ使う（2語の あいさつは使わない）。

### よむ
| レベル | カード | ことば |
|---|---|---|
| 1 | 3まい | 短いことば（4文字以下、スペースなし）。まちがいのカードは同じテーマから |
| 2 | 4まい | どのことばも。まちがいのカードは同じテーマから |
| 3 | 4まい | どのことばも。答えと同じ文字で始まることばを できれば2まい（どのテーマからでも。足りなければ同じテーマ） |

- 「ぜんぶ」・同じ回で同じことばを出さない・間違えたことばを多めに は「きく」と同じ。

### 共通
- レベルの上がり下がりは、今の教科と同じ `C.adaptive.nextLevel`。最高レベル：きく 3、よむ 3。きく・よむ は別々にレベルを持つ（テーマごと・ABC ごとには分けない）。
- 記録：きく `area: 'eigoKiku'`、`itemId` は ことばの id（ABC は `'abc:' + 種類 + ':' + 答えの文字`、例 `'abc:lower:b'`）、`level`。よむ `area: 'eigoYomi'`、`itemId` は ことばの id、`level`。

| テーマ（id） | ことば（英語・絵） |

| どうぶつ（animal） | dog 🐶, cat 🐱, rabbit 🐰, lion 🦁, elephant 🐘, monkey 🐵, bear 🐻, pig 🐷, bird 🐦, fish 🐟 |
| いろ（color） | red, blue, yellow, green, pink, orange, purple, brown, black, white（色の丸） |
| かず（number） | one〜twenty（1〜20。大きな数字） |
| たべもの（food） | rice 🍚, bread 🍞, egg 🥚, milk 🥛, cake 🍰, pizza 🍕, ice cream 🍦, juice 🧃, cookie 🍪, sandwich 🥪 |
| くだもの・やさい（fruit） | apple 🍎, banana 🍌, grapes 🍇, strawberry 🍓, lemon 🍋, peach 🍑, melon 🍈, carrot 🥕, tomato 🍅, potato 🥔, corn 🌽 |
| からだ（body） | eye 👁️, ear 👂, nose 👃, mouth 👄, hand ✋, foot 🦶, leg 🦵, arm 💪, tooth 🦷, face 🙂 |
| あいさつ（greeting） | hello 🙋, good morning 🌅, good night 😴, thank you 🙏, sorry 🙇, goodbye 👋, happy birthday 🎂 |
| かぞく（family） | mother 👩, father 👨, baby 👶, grandmother 👵, grandfather 👴, brother 👦, sister 👧, family 👪 |
| がっこうの もの（school） | pencil ✏️, book 📖, bag 🎒, clock ⏰, scissors ✂️, notebook 📓, ruler 📏, crayon 🖍️, chair 🪑, school 🏫 |

- 決まり：英語は小文字（スペースは入ってよい）。id はテーマの中で重ならない（全体では `テーマ:英語` で重ならない）。絵はすべてのことばで ちがう（同じ絵文字を2回使わない）。
- 日本語の意味（例 dog → いぬ）も持つ。正解のあと、つづりの下に小さく ひらがなで出す（例「dog いぬ」）。親画面の記録の表示にも使う。

## 6. 英語の声（`shared/voice-en.js`）
- `C.voiceEn.available()` → 通信しない英語の声（`localService === true` で、言語が en）があるか。
- `C.voiceEn.speak(text)` → Promise。読み終わったら、または 5秒たったら終わる（reject しない）。読む前に ずんだもんの声を止める（`C.voice.cancel()`）。読んでいる間は BGM を下げる（`C.sfx.duck`）。
- 声の選び方：アメリカ英語（en-US）→ イギリス英語（en-GB）→ そのほかの en。同じ中では、端末の「標準」の声を先に。速さ 0.8。
- 声の一覧が遅れて届く端末があるので、`voiceschanged` で選び直す。
- 声がない端末：英語の画面のはじめに「この たんまつでは えい{語|ご}の こえが でません」と出す（読み上げはしない）。「きく」は押せない（うすく）。「よむ」は声を使わないので、そのまま全部遊べる（答えのあとの英語は鳴らない）。
- テスト用に、声の代わりを差しこめるようにする（`_override(fakeSynth)`）。

## 7. 日本語の説明（ずんだもんの音声ファイル）
| 場面 | 画面の文（ふりがなは べんきょうの決まり：1年生の漢字はそのまま、2年生の漢字は {漢字|よみ}、3年生以上は ひらがな） |
|---|---|
| はじめ | 「どっちで あそぶ？」 |
| テーマを選ぶ | 「テーマを えらんでね」 |
| きく（問題） | 「えい{語|ご}を きいて、{絵|え}を えらんでね」 |
| きく ABC レベル1・2 | 「きこえた 文字を えらんでね」 |
| きく ABC レベル3 | 「さいしょの 文字を えらんでね」 |
| よむ（問題） | 「えい{語|ご}を よんで、{絵|え}を えらんでね」 |
| まちがい | きく「もういっかい きいてみよう」／よむ「もういっかい よんでみよう」 |
| 2回まちがえた | 「ひかっている ものだよ」 |
| ごほうび | 「よく がんばったね！ ほしが ◯こ」（はんたい ことばと同じ文。音声ファイルは今あるものを使う） |
| 声がない端末 | 画面に出すだけ（読み上げない） |

- 問題の説明は、その回の1問目だけ読む（毎回読むと英語が聞きにくくなるため）。2問目からは英語だけ。
- 日本語の説明のあとに英語を読む（声が重ならないように、日本語が終わってから）。`C.voice.speak` は終わると解決する Promise を返す（今のまま）ので、そのあとに `C.voiceEn.speak` をつなぐ。`voice.js` は変えない。
- 音声ファイルは、作業の最後に作る（やまとさんのパソコンの VOICEVOX を使う。動いていなければ起動をお願いする）。それまで「すべて音声ファイルがある」テストは、えい語の文の分だけ失敗する。〔作る人の判断〕
- `tools/voice-lines.js` に えい語の文の集め方を足し、`make.pl --preview` で読みを確かめてから作る。今ある文の読みは変えない。

## 8. 画面
- えらぶ画面（きく／よむ）：大きなボタン2つ。絵（きく＝耳と音符、よむ＝「Aa」）と名前。テーマ画面は きく・よむ の両方で出す（きく は「ABC」のカードも）。
- テーマ画面：13まい（12テーマ＋ぜんぶ）。各カードに テーマの代表の絵と ひらがなの名前。図鑑のテーマ画面と同じ並べ方（スマホよこ 5列、たて 3列）。
- 問題画面：上に ずんだもん＋ふきだし＋「もういちど きく」ボタン。まんなかに カード（3〜4まい）。下に 進み具合（点と ほし）。よむ は、問題のつづりを大きく（64〜96px）出す。
- 英語の字：つづり・文字は見やすい書体（`"Segoe UI", Roboto, Arial, sans-serif`）で大きく出す。小文字の a・g は書体によって形が変わるが、そのままにする。
- スクロールなし：スマホ 667×375・740×360・812×375・375×667・360×740・390×844、タブレット 1280×800・1024×600。字は主な字 18px 以上・補足 16px 以上、ボタン 56px 以上（高さ340px以下は48px）。

## 9. べんきょうのトップの2ページ化
- 1ページ6まい。1ページ目：九九・九九（□）・計算・かん字・{道|どう}とく・日本の{地図|ちず}。2ページ目：せかいの{国|くに}・{長|なが}さ・かさ・はんたい ことば・ずかん・えい{語|ご}。
- 「じゅんび中」のカードは もう無い（えい語を使えるようにするため）。前に足した「スマホでは じゅんび中のカードを出さない」指定は残ってもかまわない（ほかに じゅんび中のカードの数を使う所はない）。
- 2ページ目は5まい。3まい×2だんの1だん目に3まい、2だん目に2まい（6まい目の所は空ける。ちいくの2ページ目と同じ考え方）。〔作る人の判断〕
- ちいくと同じ：◀▶（よこ向きは左右、たて向きはカードの下に ◀ ●○ ▶）、●○、横にさっと動かしてめくる（`touch-action: pan-y`、めくった直後の click は のみこむ）、教科から「トップに もどる」でその教科のページ、アプリを開き直すと1ページ目、ページは保存しない。
- `B.home = { PER_PAGE: 6, pageCount(), pageOf(id), ids(page) }` を main.js に出して、テストする。
- 九九の2まい（九九・九九□）の見分けの説明（sc-sub）は、今の指定のまま出す。

## 11. テスト
- ことば：126こ、12テーマ、id がテーマの中で重ならない、英語は小文字、絵はすべて ちがう、絵文字は ZWJ を使わない、日本語の意味は ひらがな。
- `makeKiku`：レベル1は3まい・2と3は4まい、答えはちょうど1まい、まちがいは答えのテーマから（レベル3の同じ文字は どのテーマからでもよい）、`used` のことばは答えにならない、「ぜんぶ」で全テーマから答えが出る（乱数を変えて200回）。
- `makeKiku` の ABC：レベル1は大文字4つ、2は小文字4つ、3は小文字4つ＋1語のことば。答えはちょうど1つ。まぎらわしい文字が レベル2・3で入る。「ぜんぶ」で ABC とことばの両方が出る。
- `makeYomi`：レベル1は3まい・4文字以下、2と3は4まい、答えはちょうど1まい、レベル3の同じ文字、`used` のことばは答えにならない。
- `check`・`itemIdOf`・`progressFromLogs`（きく・よむ 別々に数える）。
- `C.voiceEn`：差しこんだ声で、en-US の通信しない声を選ぶ。ネットの声・日本語の声は選ばない。声がなければ `available()` が false。speak は 5秒で終わる。読む前に `C.voice.cancel` を呼ぶ。
- 画面：えらぶ画面 → きく → テーマ → 問題、正解で記録 true、2回まちがえると答えを光らせて記録 false、10問で ごほうび。声がない端末では「きく」が押せず、よむは全部遊べる。
- 日本語の説明の文の漢字：1年生はそのまま、2年生は ふりがな、3年生以上は使わない（今の かん字の決まりのテストで確かめる）。
- トップ：`B.home` で 1ページ目6まい・2ページ目5まい、えい語は2ページ目。
- 読み上げ文（日本語）がすべて音声ファイルにある。PRECACHE と公開（pages.yml）に新しいファイルが入る（今のテストで確かめる）。
- 大きさ：8つの画面の大きさで、えらぶ・テーマ・問題（きく・よむ全レベル）・トップ2ページ に スクロールが出ない。
- 実機（タブレット）での英語の声・操作は、やまとさんに確かめてもらう。

## 12. 未確認・制約
- 英語の声は端末しだい。やまとさんのタブレットでは確認済み。ほかの端末（お子さんが別の端末を使う場合）では、声がない・声がちがうことがある。
- 「good morning」「thank you」など2語のことばは、端末の声によって読み方が少しちがう。
- 絵文字の絵は端末によって少しちがう。からだ（👄 mouth、💪 arm）や あいさつ（🙇 sorry、🙋 hello）が小2に分かるかは、遊んでもらって確かめる。分かりにくければ入れかえる。
- 「えい語の画面の説明は1問目だけ読む」が聞きやすいかは、遊んでもらって調整する。
