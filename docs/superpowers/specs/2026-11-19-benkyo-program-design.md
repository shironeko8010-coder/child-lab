# 設計書：べんきょう「プログラミング」

## 1. 目的
- 小学2年生が、矢印の命令を じゅんばんに ならべて ロボットを はたまで うごかす。「じゅんばんに 考える」「くりかえしで まとめる」を 遊びながら 身につける。

## 2. 決めたこと（やまとさんと決めた）
| 点 | 決め |
|---|---|
| 命令 | 矢印（↑↓←→）。1つで1マス すすむ |
| くりかえし | 入れる（レベル4・5） |
| レベル | 5つ（下の表）。始めに「つづき」か 1〜5 を えらべる。結果で 自動に 上がり下がり |
| 1回分 | 3問で ごほうび |

| レベル | 地図 | 内容 | ならべる 場所 |
|---|---|---|---|
| 1 | 4×4 | 岩なし。まっすぐ＋1回 まがる（3〜4こ） | 6こ |
| 2 | 5×5 | 岩2〜3こ。2〜3回 まがる（5〜6こ） | 8こ |
| 3 | 6×5 | 岩4〜5こ。ほし1こを とってから はた（7〜9こ） | 10こ |
| 4 | 6×5 | くりかえしで まとめる（まっすぐの 道を「→を 4かい」など）。まとめないと 入らない | 5こ |
| 5 | 7×6 | くりかえし＋ほし2こ＋岩。かいだんの形（→↑ を 3かい など）を 見つけて まとめる | 5こ |

## 3. 遊び方（1問の流れ）〔作る人の判断を ふくむ〕
1. 地図に ロボット・はた・岩・ほし。下（よこ向きは 右）に 命令を ならべる 場所と、ボタン（↑↓←→、くりかえし、けす、ぜんぶ けす、うごかす）。
2. 矢印を おすと、ならべる 場所に 入る。「けす」で 1つ もどす、「ぜんぶ けす」で からっぽ。
3. くりかえし（レベル4・5）：「くりかえし」を おすと かっこ［ ］が 開き、つぎに おす 矢印（3つまで）が かっこの中に 入る。もう一度「くりかえし」を おすと とじる。かっこの「×2」を おすと 回数が 2→3→4→2 と かわる。
4. ならべる 場所の 数：矢印1つ＝1こ、かっこ1つ＝1こ（中の 矢印も 1こずつ）。「のこり ○こ」を 見せる。いっぱいなら「もう ならべられないよ」。
5. 「うごかす」で ロボットが 1マスずつ うごく。
   - はたに 着いた（ほしは ぜんぶ とった）：正解。
   - 岩や 地図の外に ぶつかる／はたまで とどかない／ほしが のこる：止まって やさしく 声を かけ、ロボットは スタートに もどる。ならべた 命令は のこるので、直して もう一度。叱らない。
6. 3問で ごほうび（「よく がんばったね！」）。

## 4. 問題の 作り方〔作る人の判断〕
- 毎回 自動で 作る。先に「答えの 命令」を 作り、それで 通る 道を 地図に かく（道は 同じマスを 2回 通らない）。だから かならず 解ける（答えの 命令は ならべる 場所の 数に 入る）。
- 岩は 道の上に 置かない。ほしは 道の上（スタート・はた でない マス）。
- レベル4・5は、矢印だけで ならべると 場所が 足りない（道の マス数 ＞ 5）。

## 5. 記録
- `area: 'program'`、`itemId: 'lv' + レベル`、`level`。1問1件。正解（correct）は、うまく いかなかった 回数が 1回 以下のとき true。

## 6. 画面
- よこ向き：左に 地図、右に 命令と ボタン。たて向き：上に 地図、下に 命令と ボタン。
- スクロールなし（8つの 画面の 大きさ）。ボタン 56px 以上（とても低い よこ向きは 48px）。字 18px 以上。
