# 設計書：ちいく「きおく」（カードめくり）

## 1. 目的
- 5歳の子が、うらがえしの絵カードを2まいずつ めくって、同じ絵を そろえる。字が読めなくても遊べる。集中力・記憶力。

## 2. 決めたこと（やまとさんと決めた）
| 点 | 決め |
|---|---|
| だれと | ひとりで（自分のペースで ぜんぶ そろえる） |
| レベル | 5つ。カードの まい数：レベル1＝6まい、2＝10まい、3＝16まい、4＝24まい、5＝36まい |
| レベルの えらび方 | 始めるときに えらべる（「つづき」＝いままでの記録から決まるレベル、または 1〜5 を じぶんで えらぶ） |
| 絵 | 今の ちいくに ある 絵文字（どうぶつ・たべもの など。ひらがなの 教材の 絵）。字は出さない |

## 3. 遊び方（1回の流れ）
1. 「どれに する？」：大きな ボタン「つづき」と、レベル 1〜5（まい数を 数字と カードの 絵で 見せる）。
2. カードが うらがえしで ならぶ。「おなじ えを 2まい さがそう」。
3. どのレベルも、はじめに ぜんぶの絵を 見せてから うらがえす（「よく みて おぼえてね」）。見せる時間：6・10まい＝2びょう、16・24・36まい＝4びょう（2026-11-19）。
4. 1まい めくる → もう1まい めくる。
   - 同じ絵：正解の音に 続けて（少し あけて）「そろったね！」。最後の1組は「ぜんぶ そろったね！」。2まいは おもてのまま 残る（光る）。
   - ちがう絵：1びょう見せてから うらに もどる。叱らない（声は出さない。音は やさしい「ぽこ」）。
   - 2まい 見せている あいだは、ほかの カードを さわっても めくれない。
5. ぜんぶ そろったら ごほうび（「すごい！ よく おぼえたね」）。ごほうびの「つぎへ」で 新しい ばん（2026-11-19：3回で ごほうび → 1回ごとに）。

## 4. レベルと 記録〔作る人の判断〕
- 記録は `area: 'kioku'`、`itemId` は `'lv' + レベル`、`level` はレベル。1回（1まいの ばん）を1問として数える。
- 正解（correct）：はずした回数が「組の数」以下のとき true（よく おぼえていた）。それより多いときは false（叱らない。レベルの調整に使うだけ）。
- レベルの上がり下がりは 今と同じ `C.adaptive.nextLevel`（最高5）。じぶんで えらんだときも、そのレベルから 同じように 上がり下がりする。
- 1回の 遊びの 中で 時間は はからない。1日の 利用時間の 目安（親画面）は、遊んでいる 途中では 止めず、ごほうびの あと「つぎへ」を おしたときに こえていたら お休み（案件ルール）。

## 5. 画面〔作る人の判断〕
- カードは 正方形の ボタン。板の 広さに 合わせて、いちばん 大きく なる 列の数を 選ぶ（`layout(n, w, h, gap)`）。
- 36まい（レベル5）は スマホよこで 9列×4段、たてで 6列×6段 くらい。カードは 56px 以上（とても低い よこ向きは 48px 以上）。入らないときは レベル5を そのまま、カードを 少し小さく（48px まで）する。
- スクロールなし（スマホ 667×375・740×360・812×375・375×667・360×740・390×844、タブレット 1280×800・1024×600）。
- めくるときは くるっと まわる（CSS）。そろった カードは 光る。

## 6. 読み上げ（ずんだもんの 音声ファイル）
- 「どれに する？」「おなじ えを 2まい さがそう」「よく みて おぼえてね」「そろったね！」「ぜんぶ そろったね！」「すごい！ よく おぼえたね」

## 8. テスト
- まい数（6・10・16・24・36）、組の絵が 重ならない、どの絵も ちょうど2まい。
- めくる → 同じなら そろう／ちがえば 1びょう後に もどる、2まい 見せている間は めくれない、同じカードを2回 めくれない。
- ぜんぶ そろったら 記録1件（correct の決まり）と ごほうび、「つぎへ」で 時間を こえていたら お休み。
- レベルを えらぶと そのレベル、「つづき」は 記録から。
- layout：8つの 画面の 大きさ × 5レベル で カード 48px 以上。
- 読み上げ文が すべて 音声ファイルに ある。
