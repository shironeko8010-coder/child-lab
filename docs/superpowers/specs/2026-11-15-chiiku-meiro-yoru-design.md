# 設計書：ちいく「めいろ」に「よる」と「まっくら」を足す

前の設計書：`docs/superpowers/specs/2026-11-14-chiiku-meiro-design.md`（めいろの作り方・レベル・ヒント・記録は そのまま。この設計書は 足すところだけ）

## 1. 目的
- 夜のイメージで めいろを暗くし、ひよこの まわりしか 道が見えないようにする。道を「さがす」むずかしさを足す（やまとさんの提案）。

## 2. 決めたこと（やまとさんと決めた）
| 点 | 決め |
|---|---|
| 暗さ | 全体を夜のように暗くし、ひよこの まわり1マス（3×3の9マス）だけ 道が見える |
| よる | まわり1マスだけ はっきり見える。ほかは うっすら見える（暗さ .93）。あしあとは 残らない。目じるしは ぜんぶ 光って見える（2026-11-17：前の「まっくら」の決まりを よるに した） |
| まっくら | まわり1マスの ほかは 完全に見えない（まっ黒）。あしあとは 残らない。ほしは うすくしか見えない、かぎは 見えない（どちらも 明かりの中に入ったら ふつうに見える）。ごはん・とびらは 光って見える。ヒント（光る道）は 出さない（2026-11-17） |
| 目じるし | ひる・よる：ごはん・ほし・かぎ・とびら は 光って見える。まっくら：上のとおり |
| 選び方 | めいろを始めるときに 絵のボタンで選ぶ：☀️ ひる／🌙 よる／🌑 まっくら（字が読めなくても選べる） |
| ヒント | ひる・よる は 今と同じ（6秒 動かないと 光る道）。まっくら は 出さない（かぎの場所が 分かってしまうため） |

## 3. 作る人の判断〔作る人の判断〕
- 「まわり1マス」は ひよこの いるマスと となり8マス（3×3）。壁の向こうでも 見える（5歳には 壁で さえぎると むずかしすぎるため）。
- 選ぶ画面は めいろを開いたとき（ホームのカードを さわったとき）に出す。ごほうびのあと「つぎへ」では 同じ選び方のまま続ける。
- 選んだら、よる・まっくら は ひとこと言ってから めいろを始める：
  - よる「よるの めいろだよ。ちかくしか みえないよ」
  - まっくら「まっくらの めいろだよ。ひよこの まわりしか みえないよ」
- 選ぶ画面の声：「どれで あそぶ？」（トップと同じ音声ファイル）。
- 記録・レベルの上がり下がりは 今と同じ（ひる・よる・まっくら を分けない）。むずかしさの ちがいは 子どもが選ぶ。
- テストのページ（画面なし）で モードを指定しないで始めたときは「ひる」で すぐ始める（今のテストを そのまま使うため）。

## 4. 見た目
- 暗さ：めいろの上に こい紺色（#0d1430）を かぶせ（よる .93・まっくら 1）、明るい所だけ 穴をあける（SVG のマスク）。
- よる・まっくら：明るい所＝ いまの まわり1マス（9マス）。通ったマスは 暗いまま。
- まっくら の 目じるし：ほしは 明かりの外では うすく（.3、光らない）、かぎは 明かりの外では 見えない。明かりの中に入ったら ふつうに 光って見える。
- 目じるし（ごはん・ほし・かぎ・とびら）と ひよこ・ヒントの道 は マスクの上に描く（光って見える）。
- 選ぶ画面：大きな ボタン3つ（絵＋ひらがな）。スクロールなし（8つの画面の大きさ）、ボタン 56px 以上。

## 5. テスト
- `litCells(maze, at, visited, mode)`：ひる＝null（ぜんぶ明るい）、よる・まっくら＝いまの まわり1マス（9マス）だけ1。`itemLook(mode, kind, lit)`：まっくらの ほしは 明かりの外で dim、かぎは hide、ほかは show。まっくらでは 動かなくても ヒントが出ない。
- まわり1マスの形（9マス、角では4マス）。
- start(PID, 'night') で モードが入る。動いても 明るい所は 9マス以下（あしあとなし）。
- start(PID) は ひる（今のテスト）。
- 読み上げ文が すべて音声ファイルにある（新しい2文）。
