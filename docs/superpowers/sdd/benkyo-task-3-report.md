## テストで固定したこと（計画 Step 1）
- 初期状態で `a × b = ?` が出て、正解入力＋「こたえる」で正解。記録は true が1件、level は出題時のレベル。
- 1回目の誤答：入力が空に戻り同じ式、「もういっかい やってみよう！」。2回目：式が `a × b = 答え`、「こたえは N だよ。つぎは できるよ！」、次の式は別の式。記録は false が1件だけ。1回まちがえてから正解も false 1件。
- 空のまま「こたえる」：何も変わらず（tries も増えない）、記録0件。
- 数字は2桁で止まる、「けす」で1桁戻る。`0`＋1桁（例 `09`）は正解。
- 5問目で星1つ、10問（2回まちがえた問題も1問に数える）で `reward`。ごほうび中は数字が効かない。「もういっかい」で solved/stars が0から。
- 「7のだん」選択で以降すべて a=7、「じどう」に戻すとレベル1の範囲（a≤2）。
- 直近5問で4問正解でレベル1→2。記録の正誤は `[true,false,true,true,true]`。
- レベル8（記録4件を事前投入）から正解を続けても8のまま。
- 問題と問題のあいだで `B.checkRest()` を呼ぶ（問題の途中では呼ばない）。true なら `rest` で止まり、数字も「こたえる」も効かない。

## 判断したこと
- **記録は1問1件**（計画どおり）：1回目で正解なら true、それ以外（まちがえてから正解・こたえを見た）は false。空入力は数えない。
- **段をえらんでいる間は、じどうのレベルを動かさない**（1のだんだけの練習で9のだんまで開かないように）。記録は残り、苦手（missCounts）にも反映する。
- 段を切りかえると、いまの式（まだ答えていない式）をその段の式に取りかえる（記録しない）。正解/こたえ表示中なら次の式から。
- 星は「5問ごと」（正解でなくても5問すすめば1つ）。設計書の「5問ごとに星」に合わせた。そのため1区切りの星は常に2つ。
- 正解のあとは1.3秒、こたえを見せたあとは3秒で自動で次へ。表示中に「こたえる」を押すと早めに次へ（数字ボタンは効かない）。
- 利用時間の確認は「次の式に進む前」と「もういっかい」を押したとき。10問目のあとはごほうび画面を先に出す。
- 読み上げ：新しい式で `speakText`（「さん かける よん は？」）、こえボタンでもう一度。正解は「せいかい！」、誤答は「もういっかい、やってみよう！」、こたえは文言どおり。読み上げが使えない端末では、こえボタンを出さない（知育と同じ）。
- 効果音：数字・けす＝tap、正解＝correct、誤答＝oops（やさしい音）、星＝star、ごほうび画面＝star。
- 画面の文言はひらがなのみ（「問」は小3なので「もん」）。
