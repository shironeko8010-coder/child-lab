# ひらがな46字 拡張 報告

## 結論
- ひらがな教材を10字から基本46字（あ〜ん）に広げました。テストは **PASS 51 / FAIL 0**。
- なぞり判定は、46字すべてで合格できることをブラウザで確かめました。新しい字の中に、極端に厳しい字はありません。
- 4字・5字の長い言葉が、カードの中で途中から折り返されていたので、最小限の修正を入れました（game.js・app.css）。

## なぞり判定の確認
1. 46字すべてで、判定用のマスク（文字の形を白黒の点にしたもの）が空にならないことを確認しました。テストにも追加しています。
2. 「理想的になぞった」場合をまねて確かめました。文字の中心線を、実際のなぞり線と同じ太さ（11%）で描いた形です。
   - ずれなしの場合：46字すべて合格（カバー率 0.88〜1.00、はみ出し 0.02〜0.19）
   - 斜めに4px（画面の約2.5%）ずらした場合：46字すべて合格
3. どこまでずれても合格できるかを、字ごとに比べました（ずれは マスク160px中の画素数）。
   - 一番厳しい字は 7px で、う・え・け・そ・た・に。う・え・け はもともとの10字に入っていた字で、新しく増えた字の中に、これより厳しい字はありません。
   - 一番ゆるい字は ぬ（12px）と へ（13px）です。
4. 実際のなぞり画面で、文字の中心線に沿って点を打つ操作をまねました。1280×800 の画面で、**46字すべてで合格し、ごほうび画面まで進む**ことを確認しました。

## 画面の確認
| 画面サイズ | 確認したこと | 結果 |
|---|---|---|
| タブレット 1280×800 | 4択（ちょうちょ・ゆきだるま・ぬいぐるみ・てをふる）、なぞり画面（ゆ）、ごほうび画面（みかん） | はみ出しなし |
| スマホ横向き 714×321 | 3択・4択、なぞり画面とごほうび画面（を・め・ぬ・ゆ・ん） | 画面の外に出る部品なし（位置を数値で確認） |
| スマホ縦向き 375×812 | 4択 | はみ出しなし |
| 親画面（375幅） | にがてな字（を・ぬ・め・ゆ・る）の表 | 崩れなし |

- 修正前は、1280×800 の4択で「ゆきだ／るま」のように、言葉が途中で2行に折り返されていました。修正後は1行に収まります。
- 「を」「ん」のカードでは、「て**を**ふる」「みか**ん**」のように、その字が色付きの太字になります。
- 親画面の苦手表は、まちがいの多い上位5字だけを出す作りなので、46字に増えても崩れません。

## 確認していないこと
- 実機（Androidタブレット・古いAndroid）で、絵文字が□にならずに表示されるか。特に 🧸🧼（Unicode 11）。
- 実機の指で、本当になぞって合格できるか。ブラウザで操作をまねただけです。
- 音声読み上げで「を」「てをふる」「みかん の ん」が自然に聞こえるか。読み上げは、ごほうび画面で「てをふるの、を。」「みかんの、ん。」と話す作りです。
- 内蔵ブラウザの画面写真は、スマホ横向きのとき一部が切れて写りました。部品の位置は、数値でははみ出していないことを確かめています。
