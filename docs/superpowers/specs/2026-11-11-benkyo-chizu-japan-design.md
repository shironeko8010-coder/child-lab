# 勉強アプリ（小2）「日本の 地図」 設計書（案）

作成日: 2026-11-11 / 対象: `app-benkyo/`
正本: `docs/design-spec.md`（全体）、`docs/superpowers/specs/2026-11-08-benkyo-kuku-design.md`（土台）。本書は教科「日本の 地図」の追加分だけを書く。
状態: **やまとさん承認済み（2026-11-11）**。11章の4点を確認し、直しを反映した。

## 1. 目的と範囲
- 日本地図で、8つの地方 → 有名な県 → 47都道府県 と、少しずつ覚える。
- 地図は「本物に近い形」（やまとさん承認済み）。47都道府県の形をSVG（線で描く絵の形式）のデータとして自分で作り、アプリ内に持つ（通信なし）。おおまかな形でよく、細かい島は省く。
- 正解すると、地図のその県に色がつき、ひとこと説明（例「青森県は りんごが 日本一！」）が出て、声で読む。
- 叱らない。まちがえたら「もういっかい やってみよう！」。
- 今回やらない: 県の形だけを見せて当てる問題、白地図への書きこみ、市町村、山・川・平野。

## 2. ホームのカード・記録
| 項目 | 内容 |
|---|---|
| カードid | `chizuJ` |
| 名前 | `日本の {地図|ちず}`（日・本は1年生の字、地・図は2年生の字なので、ふりがな） |
| 小さい字 | `{県|けん}の {名前|なまえ}と 名ぶつ`（名は1年生の字。前は2年生なので、ふりがな）。カードの名前は長いので、このカードだけ少し小さく表示する |
| 記録の area | `chizuJ`（親画面の教科名 `chizuJ: 'にほんの ちず'`） |
| itemId | `青森県・ばしょ`（県あて）／`青森県・名ぶつ`／`青森県・けんちょう`／`青森県・タッチ`。地方は `関東地方・ばしょ`／`関東地方・タッチ`（親画面の「苦手」に そのまま出るので、読める名前にする） |
| correct | 1回目で正解なら true、それ以外 false |
| level | その問題を出したときのレベル（1〜3）。レベルは九九と同じく記録から決める |

- 親画面の「苦手」には、1回目でまちがえた県・地方の名前が出る。

## 3. 段階（自動でレベルが上がる）
`Chiid.adaptive.nextLevel`（直近5問で4問以上正解なら上がる、2問以下なら下がる）をそのまま使う。九九と同じく、記録（logs）から今のレベルを出す。

| レベル | 出るもの | 選択肢の数 | 問題の種類 |
|---|---|---|---|
| 1 | 8つの地方（北海道・東北・関東・中部・近畿・中国・四国・九州） | 3つ | 地方あて（光っている地方は どこ？）／地方タッチ（「近畿地方は どこ？」） |
| 2 | 有名な県 15（下の一覧で「Lv2」に○） | 3つ | 県あて／特産物／県庁所在地／地図でタッチ |
| 3 | 47都道府県すべて | 4つ | 県あて／特産物／県庁所在地／地図でタッチ |

- 出し方: 苦手（まちがえた回数）の重みで選ぶ（`Chiid.adaptive.pickWeighted`）。同じ回の中で同じ問題は出さない。続けて同じ県は出さない。
- 問題の種類は、1回（10問）の中でまんべんなく出す（4種類を順番に回し、順番は毎回まぜる）。
- 選択肢のほかの答え（まちがいの選択肢）は、そのレベルの範囲から選ぶ。レベル3では同じ地方の県を1つ以上まぜる（地図を見て考えるように）。
- 特産物の問題では、同じものが有名なほかの県は、まちがいの選択肢に入れない（例: みかん → 愛媛・静岡・熊本は入れない）。データに `notWith`（いっしょに出さない県）を持たせる。

## 4. 問題の種類
1. **県あて**: 地図で1つの県が光る（点めつ）。「光って いる {県|けん}は どこ？」→ 県名のボタンから選ぶ。
2. **特産物**: 絵（SVGの小さな絵）＋文「りんごが たくさん とれる {県|けん}は？」→ 県名のボタン。工業製品も入れる（自動車・ピアノ・めがね・タオル など）。
3. **県庁所在地**: 地図でその県が光り、「{青森県|あおもりけん}の {県|けん}{庁|ちょう}が ある {市|し}は？」→ 市の名前のボタン。県名と市の名前が同じ県（青森県→青森市 など）も出す。東京都は出さない。
4. **地図でタッチ**: 「{北海道|ほっかいどう}は どこ？」→ 地図を押して答える（5章の2だんタッチ）。

- 正解: よろこぶ音＋その県に色がつく＋ぴよの ふきだしに ひとこと説明（声でも読む）→ 声を言い終わってから少し待って次へ（「つぎへ」で早めに進める）。
- **おまけの ひとこと**: 10章の「おまけ」がある県は、説明の下に2行目として出し、続けて声でも読む（どの問題で正解しても出す）。
- まちがい: やさしい音（叱らない）＋「もういっかい やってみよう！」→ 押したボタンを うすくして、のこりから選べる。2回まちがえたら、正解のボタン（タッチ問題なら正解の県）を光らせて「ここだよ」と教え、押すと次へ。
- 5問ごとに星。10問で ごほうび画面（「日本 はかせに ちかづいたね！」・もういっかい／おわる）。
- 問題と問題のあいだで利用時間を確かめる（`B.checkRest()`）。

## 5. 地図の作り
### 5-1. データ
- `app-benkyo/subjects/japan-data.js` に、47都道府県それぞれの形（SVGの `path` の d 文字列）を持つ。座標は 1000×1000 くらいの枠の中。
- 形は、県境のおもな点を経度・緯度から手で起こした、おおまかな多角形。となりの県とは同じ点を使い、すき間や重なりが目立たないようにする。
- 細かい島は省く。佐渡・淡路島・小豆島などの大きめの島は、形が分かる程度に入れるかどうか、作りながら決める（入れないと香川・兵庫の形が少し変わる）。
- **沖縄** は、九州の左下（東シナ海のあたり）に四角い枠で囲んで寄せる。九州地方の拡大でも見えるようにする。
- 北方領土などは、教科書の地図に合わせて北海道の一部として描く（点と線で大まかに）。

### 5-2. 地方ごとの拡大（小さい県を押しやすくする）
- ふだんは日本全体を表示。8つの地方は、うすい色で塗り分ける。
- **2だんタッチ**: 地図を押すと、まずその地方が大きくなる（SVGの viewBox を地方の枠に合わせて動かす）。もう一度押すと、その県を選ぶ。「ぜんたいに もどる」ボタンで日本全体に戻る。
  - レベル1（地方の問題）は1回のタッチで答える（拡大しない）。
  - 県あて・県庁の問題では、最初からその県の地方を拡大して光らせる。左上に小さく日本全体の図を出し、どのあたりかも分かるようにする。
- 押せる場所は、県の形そのもの。小さな県（東京・大阪・香川・神奈川・佐賀 など）も、拡大後は指で押せる大きさ（最低でも 44px 四方くらい）になるよう、地方の枠を決める。
- 県の名前は地図に書かない（答えが分かってしまうため）。正解したときだけ、その県の名前を地図の上に出す。

### 5-3. 色ぬり
- 正解した県は、黄色やオレンジ系の明るい色になる。
- **おすすめ: これまでに正解した県は、ずっと色がついたまま**（記録から出す）。使うたびに地図がうまっていき、「ぜんぶ ぬりたい」という気持ちにつなげる。

## 6. 画面
- タブレット横向き: 左に地図（大きく）、右に問題文・選択肢・ぴよ。
- たて長（390×780）: 上に地図、下に問題文・選択肢。
- 小さい横長（714×321 など）: 正解のあとは選択肢を かくし、返事（ひとこと）を広く見せる（地図で答えが分かるため）。
- 選択肢は大きなボタン（県名は漢字＋ふりがな）。
- 上に「おわる」・スピーカー（もう一度きく）・星の数・「レベル」は出さない（ほかの教科と同じ）。

## 7. 文字と声
- 画面の文字は、勉強アプリの表記ルールどおり。2年生までの漢字は漢字で書き、1年生の字はそのまま、2年生以上の字は `{漢字|よみ}` でふりがな。県名・市名は3年生以上の字も漢字で書き、ふりがなを付ける（例 `{秋|あき}田{県|けん}`、`{宇都宮|うつのみや}{市|し}`）。
- 声に渡す文は、漢字まじり・すき間なし（例「りんごがたくさんとれる県は？」）。読みまちがえやすい名前（大分・甲府・那覇 など）は、データに `say`（声用のよみ）を持たせ、声だけ ひらがなにする。

## 11. 決まったこと（2026-11-11 やまとさん）
1. 県庁所在地の問題は、県名と市の名前が同じ県も含めて出す（東京都を除く46県）。
