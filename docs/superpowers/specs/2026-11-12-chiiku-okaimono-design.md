# 設計書：ちいく「おかいもの」

## 1. 目的
- 5歳の子が、親なしで「お金を数えて、値段どおりに払う」練習をする。
- 値段は現実に近い2〜3けた。硬貨は 1・5・10・50・100・500円 の6種類を、レベルで増やす。
- 叱らない。まちがえても直せて、最後は必ず買えるようにする。

## 2. 遊び方（1問の流れ）
1. 品物（絵文字）と値段が出る。ずんだもんが「おにぎりは 120えん。 おかねを いれてね」と読む。
2. 下の「おさいふ」の硬貨をタップすると、トレーに1まい入る（硬貨の名前「10えん。」を読む）。トレーの硬貨をタップすると、おさいふに戻る。
3. トレーの合計は「いま 110えん」と数字で出す（読み上げない。硬貨を入れるたびに声が出ると、数えるじゃまになるため）。
4. 「かう」をタップする。
   - ぴったり → ごほうびの演出・効果音、「ぴったり！ かえたね」。次の問題へ。
   - 足りない → 「すこし たりないよ」。多い → 「ちょっと おおいよ」。金額は言わない。そのまま直せる。
   - 2回まちがえたら、ヒントを出す（5章）。
5. 5問ごとに、今の教科と同じ「ごほうび画面」。

## 3. レベル
| レベル | 使う硬貨 | 値段 | 決まり |
|---|---|---|---|
| 1 | 1・10・100円 | 10〜399えん | どのけたも 0〜4（同じ硬貨を5まい以上数えなくてよいように） |
| 2 | 1・5・10・50・100円 | 10〜499えん | なし |
| 3 | 1・5・10・50・100・500円 | 100〜999えん | なし |

- おさいふには、そのレベルの硬貨だけを並べる。どの硬貨も何まいでも出せる。
- トレーに入るのは20まいまで（画面からはみ出さないように）。21まい目は入らず、軽い効果音だけ鳴らす。
- レベルの上がり下がりは、今の教科と同じ `C.adaptive.nextLevel`（最高 3）。
- 1問の「せいかい」は、1回目の「かう」でぴったりだったとき。記録は `area: 'okaimono'`、`itemId` は品物の id。

## 4. 品物と値段

## 5. ヒント（2回まちがえたら）
- 足りないとき：あといくら要るかを、そのレベルの硬貨で、まい数が一番少なくなるように分ける。その硬貨を、おさいふの中で光らせる（例：あと 15えん → 10円玉・5円玉が光る）。「ひかっている おかねを いれてみよう」と読む。
- 多いとき：トレーの硬貨を光らせ、「トレーの おかねを タップすると もどせるよ」と読む。
- 金額の数字は、ヒントでも読み上げない。

## 6. 画面
- タブレット横向き。左に品物の絵・よみ・値段（大きく）。右にトレーと合計。下におさいふの硬貨と「かう」ボタン。
- 硬貨の絵は SVG（図形で描く絵）。色・穴（5円・50円）・数字で区別する、かんたんな絵にする（本物そっくりにはしない）。大きさは本物と同じ順に少しずつ大きくする（1円が一番小さく、500円が一番大きい）。一番小さい1円玉でも、5歳の指でタップしやすい大きさにする。
- 知育のホームに「おかいもの」のボタンを足す（7個になる）。はみ出さないことを確かめる。

## 7. 読み上げ（ずんだもんの音声ファイル）
| 文 | 部品 | 数 |
|---|---|---|
| 問題 | 「<よみ>は」｜「Nえん。」｜「おかねを いれてね」 | 品物16＋値段990＋1 |
| 硬貨をタップ | 「Nえん。」（値段の部品と同じ。1・5 も作る） | 値段と共通 |
| かう | 「ぴったり！ かえたね」「すこし たりないよ」「ちょっと おおいよ」 | 3 |
| ヒント | 「ひかっている おかねを いれてみよう」「トレーの おかねを タップすると もどせるよ」 | 2 |
| ごほうび | 今の「すごい！ 5もん できたね」を使う | 0 |

- 値段の部品は「1えん。」「5えん。」と「10えん。」〜「999えん。」。作るのに約40分かかる（1文 約2.5秒）。
- `tools/voice-lines.js` に「おかいもの」の文の作り方を足し、`make.pl --preview` と `check.pl` で読みを調べてから作る。特に「Nえん」の数の読み（例：「ひゃくにじゅうえん」）と、品物のよみ（のばす音）を確かめる。

`C.okaimono` が外に出すもの（テスト用）：
- `COINS`（`[1,5,10,50,100,500]`）、`ITEMS`、`MAX_LEVEL`（3）、`ROUND_SIZE`（5）
- `coinsFor(level)` → そのレベルの硬貨の配列
- `pricesFor(item, level)` → そのレベルで選べる値段の配列
- `itemsFor(level)` → 選べる品物の配列
- `makeQuestion(level, opts)` → `{ item, price, level }`
- `splitCoins(amount, level)` → まい数が一番少ない硬貨の分け方（大きい順の配列）
- `judge(price, total)` → `'just' | 'short' | 'over'`
- `speakText(q)` → `'<よみ>は｜<price>えん。｜おかねを いれてね'`
- `start(profileId)`

## 9. テスト
- `coinsFor`：レベル1は [1,10,100]、2は 500 以外、3は6種類。
- `pricesFor`：レベル1の値段は 10〜399 で、どのけたも4以下。レベル2は 10〜499、レベル3は 100〜999。どれも品物の幅の中。
- `itemsFor`：どのレベルでも1つ以上。すいか（500〜）はレベル1・2に出ない。
- `splitCoins`：15（レベル2）→ [10,5]、15（レベル1）→ [10,1,1,1,1,1]、880（レベル3）→ [500,100,100,100,50,10,10,10]。
- `judge`：ぴったり・足りない・多い。
- `speakText`：部品の形。読み上げ文がすべて音声ファイルにある（今の「すべて音声ファイルがある」テストで確かめる）。
- 画面：ホームに「おかいもの」がある。硬貨をタップするとトレーに入り、合計が変わる。トレーの硬貨をタップすると戻る。ぴったりで「かう」→ 次の問題。
- 実機（Androidタブレット）での操作・読み上げは、やまとさんに確かめてもらう。

## 10. 未確認・制約
- 値段の部品が約1,000文ふえるので、音声ファイルが約8MBふえる見込み（全部で約32MB）。
- 5歳の子に3けたの値段がむずかしすぎないかは、実際に遊んでもらって確かめる。むずかしければ、レベル1の値段の幅をせまくする。
