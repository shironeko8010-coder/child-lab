# 設計書：べんきょう「はんたい ことば」

## 1. 目的
- 小学2年生が、親なしで「反対の意味のことば」を身につける。
- 少し難しめにする。レベル3では、同じことばでも文によって反対が変わるもの（高い → ひくい／やすい）を考える。
- 叱らない。2回まちがえたら答えを見せて、次に進める。

## 2. 問題の形
| レベル | 形 | 例 |
|---|---|---|
| 1 ようす | 「<ことば>」の はんたいは？ → 4つのことばから選ぶ | 「大きい」の はんたいは？ → 小さい |
| 2 うごき・ばしょ・とき | 同じ | 「あける」の はんたいは？ → しめる |
| 3 文の中 | 文を見て、反対の意味の文を4つから選ぶ | 「この ビルは 高い。」 → この ビルは ひくい。 |

- レベル1・2は、組の どちら向きでも出す（「大きい」の反対も、「小さい」の反対も）。
- 1回のごほうびまで10問。5問ごとに星。今の「長さ・かさ」と同じ。

## 3. ことば
画面の字：1年生の漢字はそのまま、2年生の漢字は `{漢字|よみ}` でふりがな、3年生以上の漢字は ひらがな。読み上げは、ひらがなの「よみ」で作る（「上」を「じょう」と読まないように）。

決まり：1つのことばに反対が2つあるもの（「高い」→ ひくい／やすい、「おりる」→ のぼる／のる など）は、レベル1・2では片方の組だけにする（答えが2つにならないように）。両方の反対は、レベル3の文で考える。

## 4. 答えたあと
- せいかい → 効果音・「せいかい！」。次の問題へ。
- 1回目のまちがい → 「もういっかい、やってみよう！」。選んだボタンは うすくなり、もう押せない。
- 2回目のまちがい → 正しいボタンを光らせ、「こたえは｜<答え>｜だよ。｜つぎは できるよ！」と読む。「つぎへ」ボタンで次へ。
- 記録は1問に1回。1回目でせいかいなら true。`area: 'hantai'`、`itemId` は問題の id（`w:<組のid>:<a か b>`、`s:<文のid>`）。
- 5問ごとに星。10問でごほうび画面（「長さ・かさ」と同じ）。1日の利用時間を超えたら、次の問題の前にお休み画面。
- レベルの上がり下がりは `C.adaptive.nextLevel`（最高 3）。出題は `C.adaptive.pickWeighted`（まちがえた問題を多めに）。同じ問題は続けない。

## 5. 画面
- 教科カード：`{ id: 'hantai', name: 'はんたい ことば', sub: '大きい↔小さい', enabled: true }`。「えい語」の前に置く。アイコンは 左右の矢印（⇄）の SVG。ホームのカードは10まい（横向きは5まい×2段）。
- 上：問題（レベル1・2は「<ことば>」を大きく、レベル3は文を大きく）。もういちど きくボタン。
- 下：選択肢4つ（2×2。レベル3の文は、横向きは 2×2、たて向きは横長のボタンを縦に4つ）。
- タブレット横向きを優先。スマホ（横・たて）でもはみ出さない。

## 6. 読み上げ（ずんだもんの音声ファイル）
| 文 | 部品の形 | 数 |
|---|---|---|
| レベル1・2の問題 | 「「<ことば>」の はんたいは？」（1つの部品） | 128 |
| レベル3の問題 | 「<問題の文>」｜「どれが はんたいの 文かな？」 | 37＋1 |
| 答えを見せる | 「こたえは」｜「<答え>」｜「だよ。」｜「つぎは できるよ！」 | 答えのことば128＋答えの文37 |
| ほか | 「せいかい！」「もういっかい、やってみよう！」、ごほうびの文（今ある音声） | 0 |

- 読み上げは、ことばの「よみ」（ひらがな）で作る。`tools/voice-lines.js` で、見分け方（画面の文からふりがなを取ったもの）と、読ませる文（よみ）を組にして足す。
- 部品は「は」で始めない。
- `make.pl --preview` で読みを調べてから作る。特に、1字のことば（上・下・右・左・南・北・東・西・兄・弟・姉・妹・朝・夜・夏・冬）と、「入る」「出る」。
- 文は約330。作るのに約14分。

- `PAIRS`：`[{ id, level, group, a: { t, y }, b: { t, y } }]`（t＝画面の字、y＝よみ）
- `SENTENCES`：`[{ id, pre, word: { t, y }, post, ans: { t, y }, wrong: [{ t, y }×3] }]`

- `makeQuestion(id, rng)` → `{ id, level, kind: 'word' | 'sentence', ask: { t, y }, choices: [{ t, y }×4], answer: 正しい選択肢の番号 }`
- `pickQuestion(opts, rng)` → `opts = { level, missCounts, lastId }`
- `speakText(q)`、`answerText(q)` → 6章の形の文（画面の字の形。読み上げのときに、ふりがなを取ったものが音声ファイルの見分け方になる）
- `progressFromLogs(logs)` → `{ level, recent, missCounts }`

## 8. テスト
- `PAIRS`：レベル1は27組、レベル2は37組。どのことばも、組の中で1回だけ出る（答えが2つにならない）。id が重ならない。`t` と `y` がそろっている。3年生以上の漢字を使っていない（使ってよい漢字の一覧で調べる）。
- `SENTENCES`：37文。まちがいが3つで、答えと重ならない。
- `idsFor`：レベル1は54、レベル2は74、レベル3は37。
- `makeQuestion`：選択肢4つ、正しいものが1つだけ、問題のことばが選択肢に入らない。レベル1・2のまちがいは、なかまが同じものが先に入る（大きさのなかまは7組あるので、「大きい」のまちがい3つは すべて大きさのなかま）。
- `pickQuestion`：同じ問題を続けない。
- `speakText`・`answerText`：部品の形。「は」で始まる部品がない。読み上げ文がすべて音声ファイルにある（今の「すべて音声ファイルがある」テスト）。
- `progressFromLogs`：area が hantai だけを数える。
- 親画面に「はんたい ことば」、教科カードに hantai がある。
- 画面（ブラウザで確かめる）：1回目のまちがいで うすくなる、2回目で答えが光って「つぎへ」。記録が1問1件。10問でごほうび。ホーム10まいがはみ出さない。
- 実機（Androidタブレット）での操作・読み上げは、やまとさんに確かめてもらう。

## 9. 未確認・制約
- 「反対」は文によって考え方が分かれることがある（例：「あまい」の反対は「からい」も「にがい」もある）。そのため、レベル3では文で意味を決め、ほかに正しく見える選択肢は入れていない（例：「ごみを すてる」の まちがいに「おとす」は入れない）。実際に使って、まぎらわしすぎる問題があれば入れかえる。
- 「ビル」「テレビ」などのカタカナは、勉強アプリではそのまま書く（今の教科と同じ）。
