## 4. 子ども目線

- **読めるか**：画面の文字はすべてひらがな。問題の文字は大きく（104px）、絵カードは絵＋ことば（先頭の文字を色で強調）。5歳が読める範囲と判断。
- **迷うボタン**：ホームは「あそぶ」1つ＋小さな音符（BGM）と歯車（大人用）。問題中は左上の「いえ」と右上の音符だけ。迷う要素は少ない。
- **言葉**：正解「せいかい！」「すごい！」、まちがい「おしい！ もういっかい えらんでみよう」、なぞり不合格「もうちょっと！ いっしょに やってみよう」。どれも励まし。
- **「できた！」を押さずに迷う箇所**：何も描かずに「できた！」を押すと「ゆびで なぞってね」と出る。描いたあと「できた！」を押す必要があることは、音声「ゆびで、なぞってみよう」と大きなボタンで分かる。ただし不合格が続いた場合の出口が無い（下の問題 A）。
- **なぞり判定の厳しさ**（10文字すべてで、合成した線を判定。○＝合格、×＝不合格）

| なぞり方 | 結果 |
|---|---|
| 文字の線の真ん中を正確になぞる | 10文字とも ○ |
| 正確だが手ぶれあり（板の大きさの3%・6%の揺れ） | 10文字とも ○ |
| 全体が右に板の5%（板が約10cm角なら約5mm）ずれる | 8文字 ○、「い」「け」は × |
| 全体が8%以上ずれる | 10文字とも × |
| 半分だけなぞる | 10文字とも ×（合格は約6割以上） |
| 別の文字をなぞる／四角で囲む／板全体をぐちゃぐちゃ描き／角だけ描く | 10文字とも × |

  → 「でたらめ」は通さず、「ていねい」なら通る。ただ、線の細い「い」「け」は、全体が少しずれると不合格になり、5歳には少し厳しい可能性がある（問題 B）。実際の画面上でも、合成タッチで「角をぐるぐる」は不合格、「文字どおり」は合格→ごほうび→記録1件、を確認した。
