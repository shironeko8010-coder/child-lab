# 設計書：ちいく「てんつなぎ」

## 1. 目的
- 5歳の子が、1→2→3…と 数字の 順に 点を つないで、絵を 完成させる。数の 順番と、指先の 動き。
- 字が 読めなくても、数字を タッチすると 読み上げるので 遊べる。

## 2. 決めたこと（やまとさんと決めた、2026-11-27）
| 項目 | 内容 |
|---|---|
| あそび方 | 数字の 点を 1→2→3…の順に タッチ（指で なぞっても よい）。点と点の あいだに 線が 引かれる |
| 読み上げ | 点を タッチするたびに「いち」「に」…と 数を 読む |
| 完成したとき | 絵に 色が ついて 少し 動く（さかなは 泳ぐ、ロケットは 飛ぶ など）。「さかな だったね！」 |
| まちがえたとき | 点が ぷるっと ゆれて「つぎは さん だよ」（叱らない） |
| ひんと | しばらく 止まっていると、次の 点が 光る |
| レベル | 1・2・3（点の数は 下の表）。始めに えらべる（「つづき」か 1〜3）。結果で 自動に 上がり下がり |
| 絵 | 12種類。SVGで 描く |
| 記録 | 5問で ごほうび画面 |
| 背景 | FigmaのAIで 作った うすい 水彩画 3まい（うみ・そら・のはら）。真ん中が あいていて、点と数字が 見やすい |

### レベルと 絵〔点の数は 作る人の判断。やまとさんの案「1〜5／1〜10／1〜15」に 近づけた〕
| レベル | 点の数 | 絵 |
|---|---|---|
| 1 | 5〜7 | いえ・ハート・さかな・ふね |
| 2 | 9〜10 | かさ・ロケット・りんご・ほし |
| 3 | 12〜14 | ねこ・とり・ちょうちょ・くるま |

## 3. 遊び方の 細かい ところ〔作る人の判断〕
1. 「どれに する？」（つづき・1・2・3）。かげあわせ・めいろ と 同じ形。
2. 背景の上に、番号つきの 点が 出る。1 の 点は はじめから 赤（出発点）、次に さわる 2 の 点は 黄色（どこから 始めるか 分かるように）。「1から じゅんばんに つないでね」。
3. 次の 点に さわる（タッチ、または 指を 動かして 点の上を 通る）と、前の 点から 線が のびる。数を 読む。
4. ちがう 点に タッチ：点が ゆれて「つぎは ○ だよ」。なぞりの とちゅうで ほかの 点を 通っても、まちがいには しない。
5. 15秒 なにも しないと、次の 点が 光る（ひんと）。
6. さいごの 点まで つなぐと、さいごの 点から 1 へ 線が もどって 閉じる。絵に 色と 目などが つき、動く。「○○ だったね！」。少し 待って 次へ。
7. 5問で ごほうび（「すごい！ よく できたね」）。問題と 問題の あいだで、1日の 目安を こえていたら お休み。

## 4. 記録
- `area: 'tentsunagi'`、`itemId`：絵の 名前（例 `sakana`）、1問1件。まちがいタッチが 0回なら true。
- 親画面の 表示名は「てんつなぎ」。

## 5. 画面
- 絵は viewBox 400×300 の SVG。背景画像の 上に うすい 白を 重ねて、点を 見やすく する。
- 点の 当たりは 半径 30（指で 押しやすく）。数字は 点の 中に 書く。
- スクロールなし（8つの 画面の 大きさ）。ボタン 56px 以上。

## 6. 読み上げ
- 新しく 作る：「1から じゅんばんに つないでね」「つぎは ○ だよ」「○○ だったね！」「すごい！ よく できたね」と 数（いち〜じゅうよん）。
- ある 音声：「どれに する？」。
- VOICEVOX の 音声ファイルが まだ ない 文は、端末の 音声で 読む（いつもと 同じ）。
