# 設計書：ちいく「しりとり」

## 1. 目的
- 5歳の子が、親なしで「ことばの さいごの音と、はじめの音」に気づく練習をする。
- アプリのキャラ（ひよこ。声は ずんだもん）と交代で、しりとりをつなげる。
- 叱らない。まちがえても、最後は必ずつながるようにする。

## 2. 遊び方（1回の流れ）
1. ひよこが最初のことばを言う。「しりとり、はじめるよ！ さいしょは… りんご。」
2. 子どもの番：「ご」から始まる絵を、絵カードから選ぶ。
3. ひよこの番：子どものことばの最後の音から始まることばを、ひよこが言う。「じゃあ ぼくは… らっこ。」
4. 2と3をくり返す。子どもが5回つなげたらゴール。ごほうび画面を出す（今の教科と同じ）。
   - 最初のことば1つ＋子ども5回＋ひよこ4回で、10個つながる（子どもの5回目でゴール。ひよこは答えない）。
5. ひよこが続けられることばがなくなったら（ふつうは起きない。7章）、「うーん、おもいつかないや。 きみの かち！」と言って、そこでゴールにする。

## 3. 子どもの番
- 絵カードを押すと、そのことばを読み上げてから判定する。
- 正しい（はじまりの音が合っていて、「ん」で終わらない）：正解の効果音。カードが上の列（つながったことば）に入る。
- はじまりの音がちがう：「◯から はじまる ものだよ。 もういっかい！」。そのカードは うすくなり、もう押せない。
- 「ん」で終わることば（レベル3だけ出る）：「んで おわると つづかないね。 ほかのを えらぼう！」。そのカードは うすくなる。まちがい1回に数える。
- 2回まちがえたら、正しいカードを光らせ、「ひかっている えを おしてね」と言う。
- 1つのことばの「せいかい」は、1回目で正しいカードを押したとき。

## 4. レベル
| レベル | カードの数 | ヒント | まちがいのカード |
|---|---|---|---|
| 1 | 3まい | つなぐ音（例「ご」）を大きく出し、読み上げる | はじまりの音が まったくちがう |
| 2 | 4まい | つなぐ音を大きく出すが、読み上げない | にている音（「ご」と「こ」のように、てんてんだけちがう）があれば1まい入れる |
| 3 | 4まい | なし | 「ん」で終わることばが そのつなぐ音にあれば1まい入れる（例「ご」→「ごはん」） |

- まちがいのカードは、つながったことばに出ていないものから選ぶ。同じ回で、同じことばは2回出さない。
- レベルの上がり下がりは、今の教科と同じ `C.adaptive.nextLevel`（最高 3）。子どもの番1回を1問として数える。
- 記録は `area: 'shiritori'`、`itemId` は子どもが選ぶべきだった ことばの id。

## 5. ことばと絵
絵は今のアプリと同じ絵文字（Unicode 12 以前）。カードには絵の下に ひらがなでことばを書く。

決まり：
- のばす音（ー）・小さい字で終わることばは入れない（しりとりで迷うため）。
- 外来語（ますく・ないふ など）は入れてよいが、ひらがなで書く（知育アプリは ひらがなだけ）。
- てんてんは そのままつなぐ（「たまご」の次は「ご」。「こ」ではない）。
- **はじまりの音1つにつき、ことばを3個以上**入れる。3個そろわない音（え・け・つ・ぬ・ぶ・や・ゆ・わ・ぎ など）は使わない。その音で終わることば（いぬ・くつ など）も、続けられないので入れない。

## 6. 画面
- タブレット横向き。
- 上：つながったことばの列。絵カード（小）を矢印でつなぐ。各ことばの最後の音を色で目立たせる（例「りん**ご**」）。長くなったら、新しい4つだけを見せる。
- まんなか：ひよこと ふきだし。レベル1・2は つなぐ音を大きく出す（「**ご**」から はじまる ものは どれかな？）。レベル3は「つぎは どれかな？」。
- 下：選ぶ絵カード 3〜4まい。
- ひよこの番の間は、カードを押せない。ひよこのことばのカードが、列に入る動き（短く）をつける。
- 知育のホームに「しりとり」のカードを足す（8まいになる。横向きは4まい×2段）。色は新しい色、絵は「2つの丸を矢印でつないだ」SVG。たて向き（3まいずつ）で最後の段が2まいになるときは、まんなかに寄せる。

## 7. ことばの選び方
- 最初のことば：「ん」で終わらず、その最後の音から子どもが選べることばがあるもの。
- 子どもの正しいカード：つなぐ音から始まり、「ん」で終わらず、まだ出ていないもの。さらに、その最後の音から ひよこが続けられることば（まだ出ていない、「ん」で終わらない、その先に子どもの正しいカードがある）が あるものから選ぶ。
- ひよこのことば：子どものことばの最後の音から始まり、「ん」で終わらず、まだ出ていないもの。その最後の音から始まる、まだ出ていない「ん」で終わらないことばがあるものから選ぶ。
- 選べるものがなければ、2章の5（ひよこの「きみの かち！」）にする。
- 子どもの正しいカードは、今の教科と同じ `C.adaptive.pickWeighted` で、まちがえたことばを多めに選ぶ。

## 8. 読み上げ（ずんだもんの音声ファイル）
| 場面 | 文（｜は部品の区切り） | 数 |
|---|---|---|
| ことば | 「<ことば>。」 | 98 |
| はじめ | 「しりとり、はじめるよ！」｜「さいしょは…」｜「<ことば>。」 | 2 |
| 子どもの番（レベル1） | 「<音>から はじまる ものは どれかな？」 | 30（はじまりの音の数） |
| 子どもの番（レベル2・3） | 「つぎは どれかな？」 | 1 |
| ひよこの番 | 「じゃあ ぼくは…」｜「<ことば>。」 | 1 |
| はじまりがちがう | 「<音>から はじまる ものだよ。」｜「もういっかい！」 | 30＋1 |
| 「ん」で終わる | 「んで おわると つづかないね。」｜「ほかのを えらぼう！」 | 2 |
| ヒント | 「ひかっている えを おしてね」 | 1 |
| ひよこが続けられない | 「うーん、おもいつかないや。」｜「きみの かち！」 | 2 |
| ゴール | 「すごい！ 5かい つながったね！」 | 1 |

- 正解のときは、効果音と、選んだことばの読み上げだけにする（毎回ほめことばを言うと長くなるため）。
- 部品は「は」で始めない（VOICEVOX が「ワ」と読むため）。
- `tools/voice-lines.js` に しりとりの文の作り方を足し、`make.pl --preview` と `check.pl` で読みを調べてから作る。特に「◯から」の1音（例「ごから」「はから」）と、のばして読むことば（こおり・ひこうき・とけい・ろうそく）を確かめる。
- 文は約170。作るのに約8分。

`C.shiritori` が外に出すもの（テスト用）：
- `AREA`（'shiritori'）、`WORDS`（`{ id, word, pic }` の配列）、`MAX_LEVEL`（3）、`GOAL`（5）
- `firstKana(word)` / `lastKana(word)` → はじまり・最後の音
- `endsN(word)` → 「ん」で終わるか
- `similar(kana)` → てんてんだけちがう音（「ご」→「こ」。なければ null）
- `pickStart(used, rng)` → 最初のことば
- `pickReply(kana, used, rng)` → ひよこのことば（なければ null）
- `makeChoices(kana, level, used, opts)` → `{ answer, cards }`（cards は 3〜4まい、answer を1つだけふくむ）
- `judge(kana, wordObj)` → `'good' | 'wrong' | 'n'`
- `speakAsk(kana, level)` / `speakWrong(kana)` → 読み上げ文
- `start(profileId)`

## 10. テスト
- `WORDS`：98個。はじまりの音それぞれに3個以上。id が重ならない。ひらがなだけ。「ー」や小さい字で終わらない。
- つながるか：「ん」で終わらない どのことばも、最後の音から始まる「ん」で終わらない ほかのことばがある。
- `lastKana`：「たまご」→「ご」。`firstKana`：「ごりら」→「ご」。`endsN`：「みかん」→ true。`similar`：「ご」→「こ」、「こ」→「ご」、「あ」→ null。
- `makeChoices`：レベル1は3まい、2・3は4まい。正しいカードはちょうど1まいで、つなぐ音から始まり「ん」で終わらない。出たことばは入らない。レベル2で「ご」なら「こ」で始まるカードが入る。レベル3で「ご」なら「ごはん」が入る。
- `pickReply`：「ら」→「らっこ」か「らじお」（らいおんは選ばない）。出たことばは選ばない。続けられなければ null。
- `judge`：good・wrong・n。
- 何回くり返しても（乱数を変えて100回）、ひよこが続けられなくなる前に5回つながる。
- 読み上げ文がすべて音声ファイルにある（今の「すべて音声ファイルがある」テストで確かめる）。
- 画面：ホームに「しりとり」がある。正しいカードを押すと列に入り、ひよこの番のあと次の問題になる。
- 実機（Androidタブレット）での操作・読み上げは、やまとさんに確かめてもらう。

## 11. 未確認・制約
- 絵文字の絵は端末によって少しちがう。さい🦏・らっこ🦦・ますく😷・ねくたい👔・みかづき🌙・そろばん🧮 などが5歳に分かるかは、実際に遊んでもらって確かめる。分かりにくければ ことばを入れかえる。
- 「とけい」「こおり」は、読むと「とけー」「こーり」に聞こえる。しりとりでは ふつう「い」「り」でつなぐので、そのままにする。
