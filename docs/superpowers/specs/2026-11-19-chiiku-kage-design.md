# 設計書：ちいく「かげあわせ」

## 1. 目的
- 5歳の子が、黒い かげ（シルエット）を 見て、同じ形の 絵を えらぶ。形を よく見る力。字が 読めなくても 遊べる。

## 2. 決めたこと（やまとさんと決めた）
| レベル | えらぶ数 | 内容 |
|---|---|---|
| 1 | 3つ | 形が まったく ちがう 絵から えらぶ（ちがう なかま） |
| 2 | 4つ | まだ 見分けやすい（ちがう なかま） |
| 3 | 4つ | にた なかま（どうぶつ どうし など）が まざる |
| 4 | 6つ | にた なかまだけ |
| 5 | 6つ | にた なかまだけ。かげが 左右 はんたいの ことも ある |
- 1回分：5問で ごほうび。まちがえても 叱らない。
- レベルは 始めに えらべる（「つづき」か 1〜5）。結果で 自動に 上がり下がり。

## 3. 遊び方〔作る人の判断を ふくむ〕
1. 「どれに する？」（めいろ・きおく と同じ）。
2. 大きな かげ と、下に 絵の ボタン。「おなじ かたちは どれかな？」
3. あたり：正解の音に 続けて「せいかい！」。かげに 色が ついて 本物の 絵に なる。少し 待って 次の問題。
4. はずれ：そのボタンを うすくし、「もういっかい、えらんでみよう」。2回 はずれたら 正解の ボタンを 光らせて 「これだよ」（さわると 次へ）。
5. 5問で ごほうび（「すごい！ よく みつけたね」）。問題と 問題の あいだで、1日の 目安を こえていたら お休み（ほかの 遊びと 同じ）。

## 4. 記録
- `area: 'kage'`、`itemId: 'lv' + レベル`、1問1件。1回目で あたりなら true。

## 5. 絵
- 絵文字（Unicode 12 以前）を「なかま」に 分けて 持つ（どうぶつ・たべもの・のりもの・むしと 生きもの・どうぐ）。かげは 絵文字を CSS で まっ黒に して 作る。
- レベル1・2：答えと ちがう なかまから えらぶ（同じ なかまは 入れない）。レベル3：答えと 同じ なかまを 2つ以上。レベル4・5：ぜんぶ 同じ なかま。
- レベル5：半分くらいの 問題で かげを 左右 はんたいに する。

## 6. 画面
- スクロールなし（8つの 画面の 大きさ）。ボタン 56px 以上。たて向きは かげが 上、ボタンが 下（2列 または 3列）。

## 7. 読み上げ
- 「おなじ かたちは どれかな？」「これだよ」「すごい！ よく みつけたね」（新しく 作る）。「どれに する？」「せいかい！」「もういっかい、えらんでみよう」（ある 音声）。
